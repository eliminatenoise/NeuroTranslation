# Reproduce a forecast

The starting point is a person turning a supported right wrist towards a target on a screen. Each forecast receives the previous 256 stored rows and looks 128 rows ahead. The recording files use a 512 Hz clock. The authors report a nominal encoder refresh of 100 Hz, so the same physical reading can appear on several rows. Sensors, hardware and filters can each contribute delay. [Data descriptor](https://doi.org/10.1038/s41597-026-07287-z)

## Run the invented example

Use a Python environment with NumPy and CPU PyTorch installed. The experiment used Python 3.13.15, NumPy 2.4.6 and PyTorch 2.14.1+cpu on Linux. Run `python -B predict.py` to read the included example, or supply a file with `--input filename.json`. The `--mode` option accepts `motion`, `emg`, `full` or `all`. The reader checks the model and scale files and uses one CPU thread. The example predictions come from the supplied weights on invented input and carry no accuracy estimate.

| JSON field | Meaning |
| --- | --- |
| `target_offset_after_cue_ticks` | The number of stored rows from the visual cue to the requested angle. Choose 384, 512, 640, 768, 896 or 1024. The last available sample is 128 rows before that time. |
| `anchor_deg` | The latest measured extension and radial-deviation angles, in that order. Extension and tilt towards the thumb are positive. |
| `mean_angles_deg` | Sixteen rows of two absolute angle means, in degrees. Each averages 16 consecutive source rows. Enter the oldest bin first. The forecaster subtracts each axis’s latest angle. |
| `emg_rms_uv` | Sixteen rows of four nonnegative forearm amplitudes, in microvolts. For each source pair M1 through M4, subtract R from L on each source row, then compute the square root of the mean squared difference within the bin. The EMG and full modes require this field. |
| `eeg_mean_uv` | Sixteen rows of eight mean scalp voltages in microvolts, ordered C3, C1, Cz, C2, C4, CP3, CPz, CP4. The full mode requires this field. |

The paired forearm voltages were measured at the skin. Their differences and short-window amplitudes are derived quantities. Muscle force, peripheral nerve traffic and sensory feedback were outside the recorded measurements. Scalp and forearm signals can both include movement or contact artifacts.

## Trace the fit and scores

1. The November 19 wrist studies fixed the whole-person split and the independent checks for matching the EEG and encoder tracks. They also supply their public data preparation and feature code. The Figshare release retains the original recordings and licence. Use the study’s existing six fitting roles and three exploratory roles only for an authorized reproduction. Reserve the six confirmation participants and preserve all excluded trials and runs. [Earlier temporal study](https://github.com/eliminatenoise/NeuroTranslation/tree/main/benchmarks/wrist-pointing-temporal) · [Paired muscle study](https://github.com/eliminatenoise/NeuroTranslation/tree/main/benchmarks/wrist-pointing-muscle) · [Dataset](https://doi.org/10.6084/m9.figshare.29666735.v3)
2. From each eligible trial, form the six requested target events. Require a complete history, a valid measured target, and finite features for every input set. Keep participant, block, trial and offset together. The complete training set had 1,879 trials and 11,274 two-angle targets. The exploratory comparison removed all six windows of one published example before constructing the wrong-trial donors. This left 959 trials and 5,754 two-angle targets.
3. The included model adapter defines the feature frames, source units, observations, target time checks and training phase. The same sixteen bins, final measured angle, and cue offset feed all fits. The output of each network is its predicted change from the last measured angle. The predictor converts the change back to degrees and restores that last angle. [Shared model](broader_learner.py) · [Wrist adapter](study_model.py) · [Target alignment checks](aligned_forecast.py)
4. The three fits used all training rows, the same initialization, four complete epochs, identical seeded shuffling, and frozen training-only scales. The reported model is the last epoch in each case. No selection used exploratory scores. Linear comparators reused previous fitted weights. For the wrong-trial comparisons, advance the voltage history to the next eligible trial of the same person and block, at the same offset after the cue, wrapping at the end. The target and the rest of its history stay with their own trial. [Four-epoch fitting loop](fit_epochs.py) · [Settings](protocol.json) · [Model and source hashes](model-sources.json)
5. For each method and person, calculate squared error separately for the two angles. Average the two axis errors after giving every person equal weight, then take the square root. Pair methods on the same rows. The aggregate file also retains per-axis errors, the range of contrasts after removing each person in turn, descriptive percentiles of the 27 ordered three-person resamples, and marginal interval coverage. It contains summaries only. Recomputing these cohort scores requires the admitted recordings and the original role and event receipts. [Numeric results](results.json)

The dedicated launchers open the offline HTML summary through the system browser. The Linux launch command and the predictor were exercised on Linux. Native Windows and macOS execution was not observed for this edition.


The fitting function accepts a previously checked local table. Its `rows` object carries `bins` (forecast × 16 × 14), `anchor` and `target` (forecast × 2), and zero-based `slot`. The 14 bin features are two anchor-relative angles, four forearm RMS amplitudes and eight scalp means. Alongside these are the role, run identifiers (`parent`), and source cue ticks (`cue`). The separate `events` table supplies each retrieved target’s run, source row, cue row and measured angles as `parent`, `tick`, `cue` and `value`. Every row must align with the role roster and the source extraction. The public package supplies the training loop, the three fitted states, the implementation that scores an input, and cohort summaries. Private event-level tables and identity receipts stay with their original custodian.
