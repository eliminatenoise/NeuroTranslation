# NeuroTranslate 0.0 force and waist forecasts

Try a 100 ms forecast and compare the latest-mean and trend rules with ridge regression and shared attention. The checkpoint can read a force history or a waist-watch history. Each uses its own measurement units and clock. [Download the forecast package](Native-Force-and-Waist.zip)

The browser preview lets you change the earlier readings and see all four forecasts update. The browser package includes a standalone page and three desktop launchers. [Open the browser preview](https://eliminatenoise.github.io/NeuroTranslation/walking-force/force-and-waist/) · [Download the browser package](Force-and-Waist-Browser.zip)

For the command-line program, extract `Native-Force-and-Waist.zip` and open `Run-Forecasts.sh` on Linux, `Run-Forecasts.command` on macOS, or `Run-Forecasts.cmd` on Windows. The examples use generated readings. Python 3.10 or later with NumPy is required. [Simple instructions and results](SIMPLE.md) · [Technical instructions and results](TECHNICAL.md)
