# Forecasting the index-finger sensor

Can forearm muscle activity improve on the recent sensor trace? This experiment uses two days of self-selected isometric finger contractions. At each cutoff it predicts the index sensor voltage twelve 100 Hz ticks ahead. The comparison was fixed before the model was fitted. [Read the protocol](PROTOCOL.md).
