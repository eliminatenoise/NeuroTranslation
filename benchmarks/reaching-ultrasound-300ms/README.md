# NeuroTranslate 0.1 reaching forecasts

[Run in your browser](https://eliminatenoise.github.io/NeuroTranslation/reaching-ultrasound-300ms/) · [Download the offline browser ZIP](https://eliminatenoise.github.io/NeuroTranslation/reaching-ultrasound-300ms-offline.zip) · [Download the Python package](https://github.com/eliminatenoise/NeuroTranslation/releases/tag/reaching-ultrasound-300ms-2026-11-26)

Start with the invented example or open a compatible local JSON history. For the offline ZIP, extract the whole folder and open `index.html`. The Python package uses NumPy.

The study forecasts how far points on each muscle will be spread around their centre in an ultrasound image 300 milliseconds later. It compares complete ultrasound history, a recent gap and all ultrasound withheld. With the recent history available, a simple linear forecast led the comparison on five validation participants.
