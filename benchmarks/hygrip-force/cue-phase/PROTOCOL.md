# Does grip history mean something different at a cue change?

When the next instruction is to relax, an upward bend in grip voltage may be less useful for forecasting than the same bend in the middle of a contraction. We test one prediction that follows from that idea. A small set of phase-dependent coefficients should improve a six-sample forecast of the released voltage over a model that uses the same cue and grip inputs with shared coefficients. This is a forecast of a measured signal, with the scheduled cue as context. The association cannot identify actual contraction onset, a physiological switching mechanism, a neural state, or feedback control. [HYGRIP descriptor](https://doi.org/10.3389/fnins.2020.00919).

## Clock and model arms

Interpret the stored IEEE Go timestamp `g` exactly. The grid origin is `floor(50g + 1/2)`. Issue at `i = origin + 20 + 5j` for `j = 0,…,204`. For each issue take `V[i−19 : i+1]` and target `V[i+6]`. Force history and target must lie within the half-open force interval from the first native tick at or after Go to the first native tick at or after the earlier of the next marker or Go plus 21 s. Define `τ = i/50 − g`, cycle `q = floor(τ / 2.10)`, and within-cycle time `r = τ − 2.10q`. The five cue features are `τ, q, r, s(τ), s(τ+0.12)`, where `s(t)` is 1 when `t mod 2.10 < 1.55` and 0 otherwise. Exact rational comparisons govern the phase boundaries. The issue and target cue states give phase `00`, `01`, `10`, or `11`. The target cue state is a fixed schedule computed at issue and uses no future measured input.

| Arm | Prediction |
| --- | --- |
| Persistence | `V[i]` |
| Backward slope | `V[i] + 1.5 × (V[i] − V[i−4])` |
| Shared force-history ridge | Ridge fit directly to `V[i+6]`. Five cue terms, all 20 history readings oldest first, and two slopes `d80 = (V[i] − V[i−4])/0.08` and `d200 = (V[i] − V[i−10])/0.20`. This is the original 27-feature force comparator. |
| Compact residual ridge | Add a learned correction to `V[i]`. Ridge fits the measured change `V[i+6] − V[i]` using the five cue terms and `V[i], d80, d200` (eight inputs). |
| Phase-conditioned residual ridge | Same correction and eight shared inputs. Add six columns in phase order `00, 01, 10`, with `V[i]` and `d80` each centered using their fold-weighted training mean before multiplication by the corresponding phase indicator. The `11` state uses only the shared terms. There is no separate phase intercept beyond the shared cue terms. |

The compact residual ablation asks whether gating the same signal summaries by phase helps. A comparison with the full shared ridge also changes the feature budget and the fitted target (voltage versus its change), so that comparison alone cannot isolate the effect of phase. Ridge fits in the two residual arms select their penalties by the same rule, independently, on the same grid. The analytic arms have no fit or selection.
