# Run the finger-angle forecast

Unzip the entire download into one folder and open **index.html** in a browser. You can also use **Launch on Windows.cmd**, **Launch on macOS.command** or **Launch on Linux.sh**. On macOS or Linux, open a terminal in the folder and run the launcher with `sh` if your file manager opens it as text. The model runs on your device, without an internet connection after extraction.

The page estimates how much the angle at the base of a finger will change over the next 320 milliseconds. It covers index, middle, ring and pinky. The starting example contains invented readings. Choose a finger, move the slider for its last observed angle, and pick a forecast to plot. The green line shows the history. The orange dash and dot show the prediction. The table reports how much the angle is forecast to change and the angle that change would produce. To compare more forecasts, turn on **Include ultrasound forecasts**.

The recorded error table comes from another set of runs. Four people repeated an isolated index-finger bend at a medium speed. For each person, the model used for scoring was fitted with only the other three people’s recordings. We measured how far each forecast was from the recorded angle, averaged those errors for each person, then gave the four people equal weight. Every method used the same 5,532 forecast times per finger.

On the index finger, the linear model that used recent angles averaged 20.78 degrees of error. Adding the ultrasound tile values directly increased that error to 44.38 degrees. Measuring each ultrasound tile relative to the first frame in its history lowered the combined error to 23.45 degrees. The same change brought the combined recurrent model from 34.99 to 26.63 degrees. The recurrent model using angles alone averaged 24.09 degrees. For the pinky, measuring the change in ultrasound raised the combined recurrent error from 3.12 to 3.32 degrees.

The change-of-ultrasound test used the same four people and the same archived outcomes. The downloaded model was fitted again on all four people so you can run it. The table shows the separate person-by-person forecasts. Two other people are set aside for final evaluation. This study does not measure how long a live sensor takes to deliver a reading.

To use your own compatible data, open a JSON file containing ten rows under `history`, oldest first. The recorded samples were 40 milliseconds apart. Enter the angles in degrees in index, middle, ring and pinky order. The ultrasound comparisons need sixteen more values per row, one per tile in a four-by-four image grid. Prepare them using the instructions on the page. The file stays in the browser and the camera remains off.
