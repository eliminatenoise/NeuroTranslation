Vertebrate neural recordings

An electrode picks up electrical impulses. Spike sorting can assign those impulses to individual cells. A camera can follow changes in calcium fluorescence across a fish’s brain. Both record neural activity, but they answer different questions. These $count deposits show what was measured, which files were checked and where a prediction was tested.

Which recorded unit spikes next?

Spike sorting assigns detected electrical events to local clusters called units. Five coefficients fitted on one rat’s spike history were applied to other recordings with their own unit labels. Each forecast ranks the units for the next millisecond that contains a spike. Bins with multiple target spikes have no single scored identity.

Rat · hippocampus and prefrontal cortex

The original study tested later trips from the training rat and trips from a second rat. The second recording had $rat_units candidate units. A running count almost matched the fitted model’s first-choice accuracy.

Turtle · dorsal cortex

In one recording during visual stimulation, the fitted model assigned better probabilities than running counts across $turtle_n scored transitions. Log loss was $turtle_model against $turtle_count, where lower is better. Giving each target cluster equal weight reversed that comparison. The archive gives each cluster a local label with uncertain single-cell identity.

Read the turtle analysis

Salamander · isolated retina

Three visual stimuli supplied $salamander_n scored forecasts from sorted retinal ganglion-cell spikes. A rule that favoured recently active cells beat the rat fit for every stimulus. Giving each stimulus equal weight, log loss was $sal_recency for that rule and $sal_model for the fitted model. The archive does not identify an animal for each experiment.

What could a fly or worm contribute?

FlyWire traces connections in a fly brain. Reconstructions of worms at different ages show how their wiring differs across development. They can suggest which connections to test. Predicting activity in a vertebrate requires a separate experiment on a vertebrate recording.
