Vertebrate neural recordings

Can worm recordings help forecast a fish’s neural activity?

A fluorescent indicator changes brightness as calcium levels change inside a cell. Given four recent brightness readings from one region of a fish’s forebrain, can a model predict the next reading more closely if some of its training examples come from worms?

What changed in training?

Each fit used 1,024 examples. All four shared the same 768 from a single fish, Fish01. The fish-only fit spent the remaining 256 on more examples from those same regions and the same early period. The mixed fit spent those 256 on eight freely moving C. elegans worms, 32 examples per worm. Every fit used the same four adjustable coefficients and solved for them once.

Two further fits used those 256 slots to sample other regions of Fish01 or a later period from the original regions. These comparisons ask how much variation one fish could supply on its own. A fifth forecast simply carried the last brightness reading forward.

How far off were the forecasts?

Each region had its own scale. An error of one unit equals one standard deviation of that region’s fluorescence during the first 30 seconds of its recording. Mean squared error gives large misses extra weight. Mean absolute error gives the average size of a miss in those same units. Lower is better in both columns.

How was each prediction made?

The worm source supplied fluorescence from tracked neurons. The fish source supplied processed changes in fluorescence relative to baseline from one forebrain imaging plane during a temperature experiment. For each recording we took the first 180 seconds and the first 32 available regions in archive order. We used each region’s first 30 seconds to fix its mean and standard deviation. A forecast required at least 20 finite calibration readings and a positive standard deviation.

After calibration, the model read the current value and three earlier values spaced about 1.2 seconds apart. It predicted the change to the next observation, approximately 1.2 seconds ahead. We used the nearest recorded frames within 0.36 seconds of their requested times. The measured horizon in the held-out fish was $horizon seconds. The first predicted frame came $first_target seconds after the start of each recording. Inputs stayed at or before the forecast origin. Missing values and unmatched times removed a case from every comparison.

The model fitted a single linear rule across all training regions using ridge regression (penalty 0.01, no intercept). Animal identity, region identity and species never entered that rule. We sampled training examples without replacement using a fixed seed and froze all coefficients before opening the seven test recordings. In each fish we averaged errors first within each region, then across regions. The primary score is the average across fish. An independent calculation recovered all four sets of coefficients and the losses for every fish to within numerical rounding.

What does the result say about biology?

The experiment measures the value of what happens when 256 examples from one fish are exchanged for 256 from eight worms. That exchange changes species, number of animals, indicator, recording conditions and processing at the same time. No arm trained on extra fish from the same experiment. A comparison with equally many new fish would help separate the value of adding animals from the value of adding worms.

The target was a future camera measurement. The worms and fish carried different calcium indicators (GCaMP7f and GCaMP6s). Both respond over time, and the archives supplied traces processed after recording. A model can use the timing of the indicator or the way a trace was processed. Recovering electrical spikes from those signals, predicting muscle force, and testing a common rule of neural development each require their own measurements. FlyWire and the worm developmental connectomes offer wiring evidence for that separate question. Read the comparative evidence.
