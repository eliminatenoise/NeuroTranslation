Predict signed change in tracked fascicle length in millimetres, L[i+10] − L[i]. Negative is shortening. i is zero-based original tracker row 20, 30, … while i+10 < n; original source row in the file is one-based. Require all 31 original rows from i−20 to i+10 contiguous by original row with finite length, pennation and strictly increasing original tracker labels in one qualified segment. Use the same windows for all methods. Exclude unqualified rows/gaps without interpolation. Report per-trial and per-person coverage internally. Missing expected files, invalid receipts or a person with zero windows in either recording blocks the complete assessment. Horizon is ten original tracking steps; the ultrasound playback time is not established acquisition time. An offline tracking estimate may depend on smoothing or manual corrections unavailable at prediction time.

The predictor sees 21 lengths through i and 20 angles through i−1. Split the 20 intervals into five consecutive bins of four steps. Each token contains [length at bin end, length change during bin, mean of four earlier angle knots in degrees, last minus first of those four angle knots]. The last angle always precedes the length cutoff. No targets, donor identities, frame rank, time, raw images or external instrument measurements enter a predictor. Donor diagnostic: on the same fitted full model replace only the two angle features by those from the other trial of the same person at the nearest proportional *eligible-cutoff* rank; map j to floor(j*(m−1)/(n−1)+0.5), or zero if n=1. Keep only receptor length, its label and all rows. This maps complete recording ranks retrospectively, solely for a timing/recording control; it is not a deployable intervention.

All scores are mean absolute signed-increment prediction errors (mm), averaged within trial, then equally over its person's two trials, then equally over people. List participant gains internally, their range, count positive and exact two-sided sign test ignoring ties, treating independent people as the replication unit. Four people cannot resolve conventional significance even with unanimous improvement. No window-level confidence interval. Development leave-one-person-out fits learn all coefficients, scaling and constants from three people only; results descriptive given shared fitting data.

Forecasts: (1) zero, (2) repeat L[i]−L[i−10], (3) development-only weighted median target increment, (4) weighted ridge using the flattened ten standardized length features, intercept unpenalized, standardized-target squared error plus 0.01 times squared coefficient norm. (5) length-only and (6) length+angle models: same trainable architecture, zero the standardized angle channels in the length-only arm; same deterministic initialization/training. (7) other-trial angles through the full fit as above. (8) exploratory straight-line projection: projected length P[k] = L[k] cos(angle[k]); extrapolate its preceding ten-step change through the last eligible angle and divide by that angle's cosine, (P[i−1]−P[i−11])/cos(angle[i−1]). This approximates motion along a fixed local axis, conditional on a straight fascicle and the chosen reference line; along-fascicle length is the actual label. Undefined if |cos(angle[i−1])| < 0.1: then omit this exploratory method for that row and report coverage separately; it has no decision gate.

Standardize each input feature and target by train-weighted mean and population standard deviation (minimum 0.000001 in native units). Feature moments weight bins equally within each window, and windows equally within trial, with equal person and trial weights. No other scaling, clipping, augmentation or subject-specific adaptation. One transformer encoder block, 5 ordered tokens, learned positions, width 16, two heads, scaled dot-product self-attention across observed history, residual post layer normalization (eps=1e−5), 32-unit ReLU feedforward, residual post layer normalization, final-token linear output giving signed standardized change directly. No dropout. AdamW (lr=0.003, betas 0.9/0.999, eps=1e−8, decay 0.01), 120 full-batch updates of weighted standardized-target smooth L1 loss (beta=1), no early stopping, no gradient clipping, float32 Torch, seed 2718 reset for each arm/fold. No personalized fitting. Export final weights, scalers and baselines to JSON with NumPy reference inference and independent numeric parity <1e−4 mm (absolute error). Freeze design/scoring, final coefficients and source member identities before held access.

On four assessment people, first ask whether the length-only Transformer beats zero and recent-change persistence, and separately whether it beats typical and ridge. Each comparison needs lower person-balanced MAE and strictly lower per-person error in at least three of four. Claim incremental value for pennation only if the full model beats each of length-only Transformer, ridge, zero, recent-change, typical and the same fit with other-trial angles by those same two criteria on the common support. Report failures and all results. No retraining after assessment. This studies prediction in these recordings; it establishes neither biological causality nor neural drive, muscle force, EMG correspondence, clinical utility or live acquisition latency.
