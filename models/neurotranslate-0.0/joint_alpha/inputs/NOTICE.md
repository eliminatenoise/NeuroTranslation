# The recordings behind the pooled checkpoint

The joint checkpoint contains numerical weights and training-population scales learned on the listed development groups. Public distribution of this aggregate scientific preview is supported under these source terms with the credits, notices and changes below. The public input kit contains reconstruction code, human cohort selection logic and aggregate descriptions. Participant identifiers, event traces, row-level predictions, and per-person weight tables are excluded from the product.
