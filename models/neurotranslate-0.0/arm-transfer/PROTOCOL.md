# Does a movement rule fitted across people carry over to someone new?

This study keeps the seven right-arm instruction categories, three sensor channels and nine outcomes from the first-person arm study. It asks three different questions. Does fitting on more people improve the earlier shared model? Does the cue add information about a new person's instrument readings when recent motion is available? If one recorded run from that person is already available, does a small personal correction help on subsequent runs?

## People and measurements

Select Ofner et al. (2017), Zenodo record 834976, motor execution runs 1–3 per participant. The previously fixed numeric split allocates S1–S7 to fitting, S8–S12 to assessment and S13–S15 to reserve. S1’s three runs have been analyzed in full before. All other assessment people remain outside every fitted model and every choice of controls or thresholds. The fitting records can be acquired while this protocol is written. Before accessing even the headers of S8–S12, seal this protocol, executable fit and evaluation logic, parent and fitted checkpoints, and the separate task-trained model and its evaluation protocol. No assessment values may subsequently change the fit, criteria or choice of primary result. The reserve remains unopened.

Use codebook channels 93 (elbow), 94 (forearm rotation) and 68 (index-near glove). Work in the native output values; their physical units, anatomical sign, sensor calibration across people, device delays and display onset are unknown. Confirm the data format, header scaling, clocks and source channel identities in each file. Use the seven visual task codes 0x600–0x606. Require one corresponding end event before the next cue and at least 1.75 seconds between cue and end. Keep events regardless of realized movement direction, amplitude or correctness.

The cutoff is exactly 128 ticks (0.25 s) after each stored event on the 512 Hz grid. The final available mechanical sample index is the zero-based cutoff tick divided by eight, rounded down. Form four consecutive 8-sample bins on the 64 Hz mechanical grid. Each bin has the three medians and then three within-bin differences (last-four median minus first-four median). Each target is the median of eight samples ending at or before cutoff plus 0.5, 1.0 or 1.5 seconds, minus that sensor’s cutoff-bin median. Preserve all verified files, including excluded counts. Require finite values in required sample windows. The primary three-channel experiment uses only runs where all three sensor channels have at least two distinct finite values somewhere in the recording; report exactly constant or non-observed circuit exclusions separately and independently observed sensor coverage. This whole-file quality check does not establish a prospective live detector. It does not remove a trial for exhibiting little or no movement. Do not guess missing channels or a replacement participant. Suppress pooled conclusions if fewer than four assessment people contribute.

## Frozen comparators

Keep the existing 24-wide time encoder, the six-to-24 projection and the definitions of the previous seven single-person methods. Train a new collection of readouts on the seven fitting participants. Give people equal total weight, then available runs within person, available tasks within run, and trials within task equal weight at each level. Centre and scale inputs using the weighted fitting means and population standard deviations. Use the same fixed ridge penalty (0.20) and unpenalized intercept as the original experiment. Four motion tokens follow the original design. The task does not enter the encoder. Compare no change; cue alone; motion alone, linear; cue with motion, linear; encoded motion alone; encoded motion plus cue; and cue plus motion with a shuffled encoder (original seed 20495). Keep the old S1-only cue and old S1 shared cue-and-motion models as frozen external baselines. Do not recalibrate them using an assessment participant in the primary comparison. Add a robust cue-only baseline: take the coordinatewise median of changes in each fitting run and task, then the median across each person's available runs, then across people within each task. All three nested medians refer only to fitting observations. The downloadable product includes aggregate fitted parameters, no individual trial, participant-specific correction, recording or assessment prediction.

For the wrong-cue control, replace the original class with each of the other six labels while holding the actual motion history fixed, then average the six absolute losses.

## Assessment on common support

For each sensor and horizon, calculate native mean absolute error. Separately standardize each absolute error by the weighted fitting-group standard deviation of that target, fixed before assessment. Calculate the primary scalar error by averaging the nine standardized errors per trial and using the same person/run/task hierarchy as in fitting. Report each sensor and each horizon, the per-task summaries, eligible people/runs/trials, and descriptive paired differences across people. For intervals, bootstrap whole assessment participants with replacement, 10,000 draws from PCG64 seed 88402. If any training target SD is below 1e-8, report native scores and withhold standardized claims. With five people these intervals can be unstable.

A consistent improvement over the S1 shared model requires the pooled shared cue-and-motion model to reduce the mean standardized error by at least 5%, with a strictly negative upper bound on the paired 95% interval and lower error for a strict majority of available assessment people. Test useful cue information by that same rule against both the new encoded motion-only model and the matched wrong-label forecasts. Test encoder advantage by that rule against the new cue-and-motion linear fit, shuffled encoder AND robust cue median. These criteria and the actual end results remain separate.

## A separate first-run calibration experiment

Freeze the predicted outputs of the population shared cue-and-motion model. For each assessment person with one qualified first run and at least one later run, compute each task’s coordinatewise median residual (observed minus predicted) using that first run only. Shrink each residual by n/(n+6) where n is the available first-run count for that task; unobserved tasks contribute zero correction. Add this fixed nine-value correction to the population prediction on runs 2 and 3. Compare against the unadapted shared model, robust fitting-group cue median and a personal cue median estimated from run 1, all on exactly the same later rows. The personal median falls back to the fitting-group cue median for a missing first-run task. Use the same training-only target standard deviations, participant weighting, uncertainty rule, minimum four eligible people and 5% threshold. A calibration advantage must meet the rule against all three controls. This uses labelled outcomes from a person’s earlier run and describes a different deployment condition. No individual correction or exemplar is distributed.
