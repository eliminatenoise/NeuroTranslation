# Recording source

The four checkpoints were fitted using walking measurements from the **Kuopio Full-Body Dataset** by Alexander Beattie, Matti Kortelainen, Paavo Vartiainen and Pasi Karjalainen. The dataset is licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The fitting process used prepared heel-position and vertical-force histories from the recordings. The browser examples are invented. The download contains fitted weights and code.

[Kuopio Full-Body Dataset](https://doi.org/10.5281/zenodo.24194741)

## Utah recordings used for the forecast comparison

The 0.6 metres per second comparison uses recordings described by Sarah Hood, Marshall K. Ishmael, Andrew Gunnell, K. B. Foreman and Tommaso Lenzi in [their Scientific Data article](https://doi.org/10.1038/s41597-020-0494-7). The [original data collection](https://doi.org/10.6084/m9.figshare.c.4962305.v1) is available under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The guide reports aggregate forecast errors computed from prepared heel and vertical-force readings.
