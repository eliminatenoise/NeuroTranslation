# Does a shared movement encoder help forecast a worn sensor's next rotation?

This design was fixed before opening any new development recording in this study. One S01 trial had already supplied simple baselines. Use the four previously designated fitting people (S01, S02, S03, S05), and then the separately designated assessment people (S10, S12, S13, S14) only after the complete fit, scoring code and controls have been sealed. Both sessions of S07 stay reserved. Two trials per person (02, 03), Experiment 2, Gracia Laso et al., Zenodo 19065545 v2, CC BY 4.0.

The target is unsigned angular change of the back-mounted orientation sensor over the next 0.10 seconds, in degrees. Use normalized quaternion distance 2 acos(|q·r|) with the dot product clipped to [0,1]. Require both preceding and following 200 stored 2 kHz sample gaps within one contiguous instructed basic task, 611 standing and 621 walking. Starting with the first 200 past samples in each block, advance cutoffs 200 samples each time. Using the future task only defines analysis support. No later voltage, preprocessing flag, quaternion, or future instruction goes into a prediction. Preserve all attrition. A prediction is about one device's orientation rather than joint angles or anatomical origin.

For the 100 ms preceding the cutoff, construct four 25 ms bins. Each has two unsigned angular quantities: endpoint change and cumulative length along the 50 intermediate sample gaps (degrees). Each of two 32-electrode regions contributes two scalar past-only voltage features (µV): the median across channels of the RMS around the channel's own bin mean, and the median across channels of the RMS of the 50 first differences. Use 51 samples including both endpoints for each bin, which permits exactly 50 differences. Exclude a channel from a bin only for nonfinite measurements in that bin, require at least 16 finite channels per region. Never use the file's filtered signals, global outlier flags or future-influenced artifact templates. Retain real zeros or constant channels. Compute the previous full 100 ms endpoint change separately. Check clocks and the raw source task map. Features must be available at the cutoff. Retain full-cross-method common support and bounded predictions in [0,180] degrees.

Compare zero change, recent 100 ms change, training median for the known task, linear residual model from task and motion only, shared frozen movement encoder from task and motion, then independently add upper-back, lower-back, or both histories. Include a linear full-electrode and a fixed-seed untrained full encoder comparison to distinguish the value of source pairing, the encoding step and pretraining. Both full encoders have the same architecture, features and readout training. Use every original spatial backbone parameter from the released NeuroTranslate movement weights (project, position, self-attention, feedforward, normalization), kept fixed. Use the original Torch SharedMotion initializer with seed 20261121 for the untrained encoder. It is a single initialization control.

Apply log1p to the six nonnegative features and scale each channel by its training-only mean and standard deviation across bins and cases (balanced by person, task and then trial; a scale below 1e-8 becomes 1). Before the encoder, suppress withheld standardized channels by zeroing them. Flatten these standardized bins (24 values) and append the centered/scaled representation from the last encoded token (24 values for encoder models). Include log1p(previous 100 ms angle) and the known binary task. Standardize readout features using training-only balanced weights. Fit a weighted ridge readout to log1p(target) minus log1p(previous 100 ms angle), with intercept unpenalized, regularization 0.05 times the identity on the other columns; no outcome-guided tuning. Retain all models, regardless of scores.

Compute the wrong-electrode control with the same fitted full model: substitute all four electrode features in each bin from the other trial of the same person and same task. Pair by proportionate chronological rank within that task from the other trial, index floor(recipient_rank * n_donor / n_recipient). Substitute electrical inputs only, preserve recipient movement, anchor and task. This keeps the files and all target histories disjoint. No substitutions for missing donor groups. A trial cannot supply its own wrong partner.

Use four leave-one-person-out development folds and one final all-four fit. Assessment uses frozen all-four parameters without any normalization from the new people. Report MAE and RMSE per task, balanced within person across tasks with trial means weighted equally within tasks; report the mean of the person-specific errors. Report both target distributions, number of people improving on both comparisons, each anonymized paired gain and an exact two-sided paired sign test (omit ties). Practical evidence for event-specific added electrode information requires full pretrained MAE at least 5% below BOTH matched motion-only pretrained and same-fit wrong electrodes, improvement on both in at least 3 of 4 people and no increase in mean error against the motion-only model in either task separately. No physiological or clinical inference. Compare the full pretrained model with full linear and the fixed random encoder separately. Never present reuse of weights or parameter count as proof that transfer improved accuracy.
