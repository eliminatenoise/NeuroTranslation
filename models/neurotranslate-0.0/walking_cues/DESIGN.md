# Forecast a walk with and without its instruction

This comparison will use the same C4/C5 rows as the directly trained sequence model and each participant must contribute both conditions. The row definition, enrolment and frame convention are in the source study plan. Only the original authorised training roster contributes fitted weights. Assess the original ten-person historical roster after all weights and scoring rules are fixed. The reserve set stays closed.

Features common to the learned motion-only and cue-aware methods are the signed three-dimensional displacement of the pelvis and heel over each of four adjacent five-frame intervals of the 21-frame history, the heel position relative to the pelvis at the cutoff, the pelvis’s measured past horizontal pace over 200 ms in m/s, and the one-hot elapsed-time offset since the first right strike. Each of the four tokens has six displacement components. For the shared encoder methods, pass the six components through the stored movement encoder’s six-input projection and four-token temporal encoder, with input columns standardized only on the fitting people and bins. Append the resulting final 24-value representation to the original features. Compare the fitted pretrained encoder and a fixed untrained, equal-shaped comparison encoder. An unchanged condition-free model receives zero in the cue columns. The cue-aware model receives a signed code (−1 usual, +1 fast), plus its interactions with each observed offset and the observed past pelvis pace. This is a declared representation of two known instructions, with explicit categorical equivalence. Swapping the instruction changes those same cue-dependent columns. Keep the recipient movement, phase, past pace and eligibility unchanged.

Each fitted model corrects a simple baseline: repeating each marker’s most recent 100 ms displacement. Center and standardize features by their weighted training mean and standard deviation, using scale one if below 1e−8. Fit an unpenalized mean residual plus linear ridge correction (penalty 0.05 applied to each coefficient; row weights sum to one). All output columns have units of mm. Train equal-shape motion-only and cue-aware linear models and shared pretrained-encoder models, plus a cue-aware fixed random-encoder comparator. Compare holding still, continuing 50 ms velocity, repeating 100 ms displacement, and mean displacement in the training records at the same condition and phase. For an absent condition/phase, use training mean at that condition and finally the global training mean. For the pace-only baseline, train the same regularized linear correction using just observed past horizontal pelvis pace and elapsed offset; it still receives recent change in both markers through the baseline. A sixth learned model uses cue and elapsed phase with a zero displacement baseline and no motion inputs; it is a second context-only comparator.

Partition sorted eligible development people by index modulo five, retaining all rows of one person in one fold. Each evaluation gives equal weight successively to people, conditions, repetitions and rows. Score the training folds with their held-person predictions, then refit once on all eligible training participants. The historical assessment uses those unmodified fitted estimates. Report separate mean 3D endpoint errors and 3-axis bias for pelvis and heel in mm. Prespecified cue test in the pretrained family: compare correct vs equal-shape no-cue fit and swapped cue through the SAME fitted model. Resample participant-level paired differences (5,000 draws, seed 1207). Require upper 95% bounds <0 for both comparisons for a given endpoint. Report whether the mean error of the method also beats all equal-access simple motion/pace baselines; this does not replace the paired test. Never pool outcomes or treat repeats as independent participants. Across two fixed source phrases, adding a cue can test task information and cannot establish extrapolation to unseen language.
