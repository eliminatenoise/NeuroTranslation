Why turn the walk?

For each forecast, two earlier positions of the pelvis define forward. Left is at right angles to that line, and up stays vertical. The model sees the same walk whichever direction it crossed the room. Turn the angle slider with the outputs set to the walker’s axes, then switch to laboratory axes.

The study used two instructions for entire walks. A phrase and its original condition code give the model exactly the same information. The coordinates follow skin markers in already filtered recordings. The test provides no spoken cue timing or measurement of a command travelling through the nervous system.
