# Can a small linear model use a scalp recording?

Fit two source-specific regularized linear predictors to the same development events as the scalp-augmented movement Transformer. This is an additional architecture comparison. It does not replace the Transformer’s four-outcome primary rule. The linear model sees 20 earlier samples of marker displacement, muscle signal amplitude, and, for the full version, three central scalp channels (signed mean voltage and RMS in each bin). Summarize the twenty bins into five successive averages of four bins. Include the current 13 named muscle masks and past RMS, three scalp availability flags, study-native posture/direction where appropriate, and a 31.25 ms velocity estimate from the last two stored position knots with their actual sample ages. Make all scalp-feature slots zero when the channel is absent. Fit scaling inside each training study and fold; center each scalp feature on available training observations only, with zero in standardized space for missing observations. The fixed comparison with reference signals replaces all the standardized scalp values by zero, keeping exactly the same dimensions and availability flags.

Use an intercept and weighted ridge regression with penalty 0.05 on the population-average squared error in standardized feature units; no optimisation of this value. Train on all available fitting events in each source under a three-way participant split (sorted identity modulo three, matching the Transformer). Give each participant equal weight and, inside a person, equal weight to each session and direction, then to events within a group. Use a separate target per observed muscle, omit unavailable training targets before fitting, predict the correction to the last 125 ms RMS and clamp the resulting amplitude at zero. Regress each of the 32 three-dimensional future positions on the same features as a correction to the last-knot straight-line velocity. A third prediction replays the trained central model on a qualifying wrong-trial scalp history using the same donor as the Transformer. Preserve all eligibility masks and the same observed movement/muscle histories. No historical or reserve rows or previous predictions used for training.

For each of the original two outcomes in each study, report the paired central-minus-reference difference in native units with 5,000 whole-person draws (NumPy seed 1641 in each study), two-sided 95% intervals and one-sided 98.75% upper bounds. Provide counts of people who improved and the same-common-support wrong-trial comparison. Give absolute performance in the same units alongside the Transformer, specialists and simple baselines. Linear training is deterministic, and both its architecture and training procedure differ from those of the neural alternatives. It uses the same observations and held participants but no stochastic update budget. Interpret gains conditionally on these development data. Preserve plausible ocular/muscle artifacts, retrospectively processed signals and source-native frames and units. Eligible masks must never be interpreted as the person's identity or neural activity.
