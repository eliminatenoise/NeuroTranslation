It cannot identify a biological cause or distinguish a measurement-frame effect from a task or dataset effect.

## Heads

Use the original 16-wide two-head Transformer, shared temporal parameters, named muscle readout, path state, time embeddings and fixed two-knot velocity extrapolation. Each timestep has 16 rectified path features. In the original model one affine map A with 16×3 weights and three biases predicts a residual. The separate model has two maps A,B; use A for balance and B for grasp. For the common, parameter-matched model, interpolate the maps' outputs as A + t × (B − A), t = (h−1)/31 at horizon h=1,…,32, for both studies. The common readout receives no direct study flag. Its inputs retain study information through the shared model. Distinct horizons make both affine maps identifiable on a sufficiently rich set of path features. The control allocates coefficients to forecast time; the intervention allocates them to the study. It does not match each map's observations or gradient frequency. Across a full trajectory, 51 output parameters are available per event for the original and separate models, 102 for the matched common model; across both studies the separate and matched models each have 102. The entire joint models contain 3,924 (original) and 3,975 (separate, matched) parameters respectively.
