Bring your own recording

The browser takes two things together. One is a model fitted on earlier events. The other is half a second of wrist, elbow, shoulder and voltage history for a single forecast.

Prepare the study model

Download the study source and follow its instructions to acquire the AJILE12 recording and fit the model locally. The versioned source explains which contacts, camera frames and movement events enter the fit. Keep your downloaded recordings and fitted parameters private.

Download the study source · AJILE12 dataset

Export an example

Use the study’s export command, or run the bundled numeric exporter with NumPy, a trusted weights archive and the prepared input archive. Substitute your local filenames below.

python export_case.py weights.npz train.npz private-case.json --row 0

The first row is 0. Without another option the exported case contains earlier inputs alone. For a training example with complete reference points, add --with-reference. The file must contain a complete history for both wrists and all eight voltage channels.

Run it in the browser

Return to the forecast. In Open a private case, choose the JSON you exported. Its fitted weights and measurements replace the generated example. No internet connection is required.
