# Walking forecast blends

Use the fixed Compact and Research Edition coefficients to combine matching physical and learned forecasts of both feet. The ZIP contains the calculator, the two coefficient files, an optional Node command and invented inputs. The complete sensor-to-forecast models are separate dependencies.
