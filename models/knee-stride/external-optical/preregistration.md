# External walking test, frozen before inspecting the knee channels

The question is whether the already published two-knee stride Transformer retains an advantage over its published stride rule and equally informed ridge correction on an independent optical recording. No learning, scaling, lag change, centering, threshold search or selection by forecast error is allowed. The review before this freeze covered the papers, manuals, archive names, HDF5 file header and public model code. No external participant angle, forecast or error was opened.

## Clock and validity

Index native 100 Hz Vicon samples consecutively in a single recording. Start each 60 Hz grid at a native sample at the beginning of the eligible interval. Use linear interpolation within that same interval on both sides together, with no extrapolation or extra smoothing, and with no interpolation across a missing native value. At model index k, the native position relative to the interval start is 5k/3. Score only k divisible by three. Thus cutoff and +15-frame endpoint both fall exactly on native observations, 25 native frames apart, and no historical interpolation stencil sees a source frame beyond the cutoff. Require an uninterrupted finite, nonzero sagittal pair at every contributing native frame from prefix start through target, conservatively excluding a possible zero code rather than bridging gaps. Also require finite/nonzero sagittal hip/knee/ankle samples from both sides over the short eligibility interval i−24 through i+15 as in the original six-joint availability mask. An exact physiological zero may thus exclude a window. Adjacent native pairs are never implicitly joined across recording breaks. The predictor consumes only 240 bilateral knee values, with the two knees in fixed R,L order. The four-second sample count spans 239/60 seconds. The target is +0.25 s. Analysis is offline and cannot prove live availability of the investigators' reconstructions.
