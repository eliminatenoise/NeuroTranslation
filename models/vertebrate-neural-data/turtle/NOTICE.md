# Sources and reuse

Shein-Idelson, Becker and Leberstein published the turtle recordings and figure material for *View invariant representations in ancestral cortex*. The Dryad dataset carries a CC0 dedication. This analysis uses cluster IDs and event times in the authors’ figure file. It converts times back to the acquisition clock, selects visual trials and reports aggregate scores. [Dryad deposit](https://doi.org/10.5061/dryad.k98sf7mm6) · [Versioned figure file](https://github.com/EvolutionaryNeuralCodingLab/SpatiallySelectiveViewInvariance/blob/b421ce0a62140a812e964cb027b97f979e98f049/spikes.mat)

The five fitted coefficients come from Justin Shin and Shantanu Jadhav’s *Single Day W-Track Learning* recordings, released under CC BY 4.0. This evaluation applies the existing coefficients to a new recording. Credit the rat recording authors and identify the model and analysis changes when reusing model-derived scores. The new turtle evaluation code is dedicated to the public domain under CC0.
