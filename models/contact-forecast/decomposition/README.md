# Did the total change, or the distribution across contacts?

A forecast can get the total number of recorded events right while assigning them to the wrong electrodes. For each original 100-ms window, split the held Poisson deviance into a term for the total count over 26 contacts and a term for the distribution of that total. Both terms use the same positive expected counts (floor of 0.000001 per contact). Divide both by 26 so their sum equals the reported deviance per contact. For zero observed total the allocation term is exactly zero. Compare each seed separately, then average scores, not its predictions. Average windows within each trial before averaging trials. Report the primary and two secondary phases separately on both all-eligible and donor-matched support. Model comparison and wrong-trial uncertainty gates remain in the primary report. This secondary breakdown, frozen before the held numerical outcomes, is descriptive. Neither component establishes which neurons fired.
