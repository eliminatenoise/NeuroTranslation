# Does a free-running path decoder help?

A secondary model forecasts two timed outcomes from the same cutoff: ten three-dimensional hand and elbow / planar handle displacements, and expected counts in the following ten bins at 23 sorted units. This comparison tests an architecture choice; it does not select or replace the primary motor or incremental-count criteria. Use original positive-lag windows in training pieces 1–4, matching the readout training population. Piece 0 stays warm-up. The only inputs are the 20 past position samples (8 native components, plus backward differences with first difference zero), 23 past spike counts per bin (log1p), and three recorded past-cue features. Standardize past feature columns using equal-original training means/variance over time, floor near-constant scales and clip normalized inputs to ±8. The eight movement outputs use fixed training RMS displacement per coordinate relative to the final input (floor 1e−6 native units). Counts retain their Poisson means per native bin. No later target coordinates or identity inputs.

All conditions use identical initial parameters for each seed 17/41/73. A shared learned-position Transformer encoder (20 tokens, width 16, two heads, one attention + width 32 feed-forward block, no dropout) uses its last token as context. Ten learned temporal embeddings and the context feed the same width-16 gated recurrent cell. (1) Parallel heads independently initialize each step's hidden state from context and supply a zero previous displacement. (2) Recurrent latent state passes its preceding hidden state but supplies zero displacement. (3) Closed rollout passes both its preceding hidden state and its own previous predicted displacement, initialized at zero. There is no teacher forcing, observation of actual future displacement, or inference from a future count. At step j the two readouts are eight normalized relative-position components and 23 positive means for the later count bin k+10+j. The parallel variant is also fit twice using the motor or neural objective alone. Its unused head cannot be reported. The joint loss is mean normalized squared motion error plus mean count negative log-likelihood; count means use softplus + 1e−6 and count biases start at inverse-softplus of each training unit's mean bin count (lower bound 0.0001). Each original contributes equally, then its available windows. Use 32 complete epochs, batch 64, AdamW 0.0015 weight decay 0.001, norm clip 1.0, deterministic matched order, no later normalization or hyperparameter selection. Independently check complete CPU training/eval and portable NumPy. Compare CPU single/two threads and available ROCm on a 20-update prefix, require native/NumPy tolerance 2e−5 on original-unit predictions and qualifying backend parameter-probe tolerance 2e−4; choose at least 10% lower cold runtime than CPU1.

Report secondary mean-trajectory and endpoint error of each tracked object in its native unit, plus delayed-count deviance per unit over 100 ms and per-bin diagnostics; include seed-specific losses and paired chronological block-8 intervals (5,000 draws, seed 20261125). Test closed vs parallel and closed vs recurrent-no-feedback on identical eligibility. Matched capacity refers to registered parameter count and optimizer schedule, not the number of effective feedback paths. To describe a consistently better joint approach at transfer, require upper paired limits below zero vs parallel for all three of hand endpoint, elbow endpoint and total-count deviance, and inspect costs/other controls. No such result establishes a physical sensory loop. This within-sample architecture study is fully separate from the chronological cross-fit experiment.
