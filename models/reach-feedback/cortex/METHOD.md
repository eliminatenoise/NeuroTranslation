# Forecasting ten later count bins

One supervised target is the number of spikes a sorted cortical unit emits in a 10 ms bin. Each head makes 230 expected counts, ten bins by 23 units, in native unit order. The first target bin starts 100 ms after the cutoff. The history ends one bin before the cutoff. The intervening ten motion samples are available at prediction time only as motor forecasts. The retrospective arm receives measured displacements. No fitting, model selection or baseline formation uses validation or test outcomes.

## Frozen comparisons

The seven fitted arms use direct history (absolute and relative pose, spikes and emitted task cues), direct history plus forecast movement, forecast alone, spikes alone, cues alone, pose and cues, or direct history plus measured movement. Every pose-aware head sees all eight measured positions in the native coordinate frame and all eight positions relative to the last known sample, using metres for hand/elbow and centimetres for handle. The absolute history recovers the same pose observations the motor model receives. Each history bin has 42 channels in total. Each forecast is a displacement from that same final known sample in its original units. Keep native counts and untransformed cue values before standardization. For each available input channel, center and scale across supported training windows and that channel's timesteps, weighting originals equally. Constant channels use scale one. Zero excluded groups *after* standardization. Never introduce trial identity, split, workspace or privileged movement into a deployable predictor.

Training uses only folds 1–4. Every original receives the same total weight, shared equally between its eligible reaches. Every arm uses all supported training reaches. The frozen motor features are genuine earlier-original expanding-fold predictions, with seeds 17, 41 and 73 matched to neural count seeds. The regression uses the corresponding ridge out-of-fold forecasts. Validation and both tests use fixed all-training motor refits from the same family. The wrong-path comparison runs the fitted full count head twice. Only the supplied forecast changes, to that of the most recent eligible strictly earlier distinct original at the same block and go ordinal, within the same split and its supported rows. Missing donors receive NaN and a donor index of −1. Source-row and local indices are distinguished. No output labels determine donors.

The Transformer reads four ordered five-bin history patches and two intervening movement patches. A 16-wide linear embedding per patch type and seven learned positional tokens feed one pre-normalized two-head self-attention layer and one residual 32-wide ReLU feed-forward layer. The first token reads all six inputs. Each arm has the same topology, active update count and 230-output softplus head with a 1e−6 floor. The masked inputs and unused linear projections keep identical dimensions. A train-only initial bias uses a common per-unit mean across target times with half a count of smoothing per unit and one extra bin of exposure in the pooled rate across ten bins and all effective original weights. Fixed seed 17, 41 or 73 initializes all trainable weights. Train for exactly 64 full-batch AdamW updates, learning rate 0.003, weight decay 0.01, default betas (0.9,0.999), epsilon 1e−8, no stochastic dropout or tuning. Minimize Poisson negative log likelihood (omit log-factorial constants), averaging over 230 targets and weighting windows by original. Record initial and final loss, gradient finiteness and final-step update count. This fixed budget does not imply a stationary optimum.

Each GLM fits a separate intercept and log-link conditional rate per bin and unit. Each five-bin patch contributes channelwise mean and a first-to-last linear trend based on all five standardized samples (least-squares slope multiplied by four bins). Both feature families therefore receive the same history and forecast groups, with a fixed lower-dimensional temporal basis in the regression. Minimize weighted mean Poisson negative log likelihood per output, with 0.35 L2 penalty coefficient on slopes and 0.02 on the intercept's departure from the pooled train log-rate anchor. L-BFGS-B in float64, up to 400 iterations, gradient tolerance 1e−7, relative objective tolerance 1e−13, maximum 50 line-search steps. Report solver termination, maximum absolute final gradient and iterations. Require successful termination, finite positive predictions and maximum gradient below 2e−4. For all training and baseline weighting, repeated windows from one eligible original collectively weigh one.

The train-mean control is the original-balanced mean delayed observed count for each of the 230 outputs. The ordinal control recalculates that mean among supported originals for that same go ordinal, falling back to the overall mean for missing ordinals. Persistence repeats the previous ten observed bins' per-unit mean in every output bin. Zeros in naive controls remain visible. The public NumPy path separately evaluates Transformer forward operations, GLM intensities and rate controls, retaining standalone learned tensors and train-only normalizers.

All choices above precede numerical fitting and held evaluation. Source processing, the comparative scoring rules and independent phase releases are specified in the study design. Output is an offline association in one recorded animal and workspace pair.
