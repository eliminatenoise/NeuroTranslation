# Predict ten measured reach displacements from twenty past samples

One token for each of 20 completed bins, each with 8 native positions (hand and elbow marker XYZ metres, handle XY cm), 8 backward increments between adjacent measured positions (first zero, since no earlier sample is supplied), 23 positive-sort counts and 3 elapsed controller values. Raw spikes use square-root counts. No time interpolation or simulated motion. Standardize each channel by its weighted mean and population SD across training windows and bins, with each original given equal total weight. Constant channels of SD below 1e-8 use scale 1. Drop a modality by zeroing all its standardized channels. Named masks full, pose_cue, spike_cue, spikes_only, cue_only. Each output is displacement relative to the final observed pose. Subtract the training-only, original-balanced mean separately for each horizon and component, then divide by the original-balanced residual RMS for that component pooled across horizons. The same scale floor rule applies.

One Transformer block, 24 features, 3 heads of width 8, learned 20-position embedding, residual attention and ReLU feed-forward layer width 48, layer normalization after each residual, final time token projected onto all 80 outputs. All 20 tokens belong to the known past; attention stays inside that window. All five input masks retain the same parameter count, seed, updates and data order for a given training set. Three fixed seeds 17, 41, 73. No dropout, data augmentation, early stopping or model selection. Train on fixed 24 epochs of seeded permutations, minibatch 64, weighted standardized MSE averaged over all 80 outputs. Window loss multiplier N/(number of originals * number of windows of that original). Divide each minibatch sum by nominal 64 (including the final partial batch). AdamW learning rate .0015, weight decay .001, default betas/epsilon, gradient norm clip 1. Float32 training, deterministic ops, no TF32, no mixed precision. MAE/RMSE metrics and time-resolved scoring belong to the frozen scorer.

The paired ridge fits exactly the same standardized/masked flattened 20-token input and scaled 80 outputs, squared loss weighted equally by original, free intercept, penalty .05 times the sum of squared coefficients. All zero-masked columns contribute zero. Solve the smaller primal/dual system in float64. Preserve all fitted coefficients, normalization and seed-specific known-motion forecasts. No fitted motion supplied to downstream training may come from its own original. For target pieces 1..4 fit all and only retained training rows in earlier pieces, with fold-specific scaling. Keep unique source identities and per-fold train/target original inventories. For deployment refit on all eligible TRAIN originals. Warmup piece 0 in OOF has supported=False and NaN, precluding confusion with stationary predictions. Train refit predictions are a fit diagnostic and stay separate.
