# Back sensor recordings and analysis

Desirée Irene Gracia Laso, Eduardo Iáñez, Mario Ortiz and José M. Azorín collected and released *An Electrospinography Database of Spinal Cord Activity During Gait-Related Tasks and Motor Imagery Exercises*. These forecasts use Experiment 2, version 2. The authors licensed the recordings under Creative Commons Attribution 4.0. [Dataset](https://doi.org/10.5281/zenodo.19065545) · [Original methods](https://doi.org/10.1038/s41597-026-07592-7) · [Licence](CC-BY-4.0.txt)

This secondary analysis converts device orientation into unsigned angles, summarizes voltage at two electrode grids, fits forecast weights and measures error in degrees. The downloadable model contains the resulting parameters, summary errors and synthetic examples. To obtain the original MATLAB files, run the source downloader against the authors’ archive. It verifies the selected members before saving them. [Acquire the recordings](source/SOURCE.md)
