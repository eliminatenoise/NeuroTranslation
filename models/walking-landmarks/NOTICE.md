# Sources and reuse

Florent Moissenet and Céline Schreiber released *A multimodal dataset of human gait at different walking speeds established on injury-free adult participants*, Figshare version 8, under Creative Commons Attribution 4.0 International. Cite Céline Schreiber and Florent Moissenet, *Scientific Data* **6**, 111 (2019). The authors' original data licence accompanies this package verbatim. [Data, version 8](https://doi.org/10.6084/m9.figshare.7734767.v8) · [Article](https://doi.org/10.1038/s41597-019-0124-4) · [Original DATA-LICENCE](DATA-LICENCE.txt) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The laboratory recorded the optical marker paths and surface muscle voltages. This analysis selected C2 recordings, extracted forty-frame histories, calculated trailing voltage summaries and twenty-frame marker displacements, fitted models and compared their errors. The fitted parameter arrays and derived scientific results retain the dataset attribution and CC BY 4.0 terms. The authors of the recordings have not endorsed this analysis.

The original software written for this package and the invented software fixture are supplied under CC0. The authors' C3D recordings, events and supplementary participant tables are available from the original sources. The participant-level score tables and the fitted event-time means can be rebuilt privately. Some event-time bins have very few contributors. The downloadable release includes the disjoint-participant aggregate scores and the model coefficients. [Software licence](LICENSE)

The authors' public MATLAB source documents gap reconstruction and forward-backward filtering. The Python extractor here reads the stored C3D positions in laboratory XYZ and muscle channels in volts.
