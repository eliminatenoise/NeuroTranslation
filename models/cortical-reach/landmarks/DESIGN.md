# Does seeing the rest of the arm change the forecast?

A secondary deterministic model tests the additional predictive value of two processed 3D landmarks for the same measured planar handle target. This comparison uses exactly the original trial partition, stage-gated access, event cutoffs, source-native coordinate order and outcome of the primary area 2 study. It runs on the common subset for which both tracked landmarks (Marker_3 on the hand and Pronation_Pt1 on the ulna) are available in every input bin. Each site contributes XYZ endpoint and 40-ms displacement in source-native shoulder-relative meters. The sites are neither the manipulandum endpoint in centimetres nor an exact elbow joint center. Other marker, inverse-kinematic and musculotendon records do not enter this secondary model. No claim of real-time raw camera availability.

Flatten the five completed rows of handle state/difference and known cue flags/directions, the two 3D marker histories and the 30 sorted count channels; add an intercept. Fit a weighted ridge regression for the two-component correction to the 40-ms constant velocity forecast. Use penalty 0.1 on the participant-session–conditional, original-trial-balanced mean squared error with intercept unpenalized. Center/scale each column only on eligible fitting rows with same training weights; zero-variance scales become one. Six established inputs: body_control = handle/available cue; body_markers = handle/cue + markers; body_neural = handle/cue + spikes; full = handle/cue + markers + spikes; markers = 3D markers alone; neural = sorted counts alone. The last two fits forecast the full target from their permitted inputs with no handle baseline. Never silently supply the encoder velocity to a marker-only or neural-only fit. Each trial has equal weight, both observed event types equal within it, then equal eligible windows. Record excluded sites/trials/rows by epoch and offset; never impute unobserved markers or use the target for input scaling.

One fitted set per method, no validation-based model, feature or penalty choice. The sealed tail remains unread for model selection. Fixed controls include stationary, velocity-40, velocity-100, velocity-200, and replacing each earlier neural or tracked-marker history in turn with the prespecified earlier trial donor on identical primary eligibility, with other modalities unchanged. The original 3D subset and all common donor supports must be reported; do not use any optional marker test to shrink the main neuronal comparison. Apply the same coefficients and training normalization unchanged to validation and then, only after joint clearance, test. Store raw two-component predictions and exact coefficients; separate privately kept trial predictions from published aggregates as needed.

Compare 100-ms Euclidean error in cm. Primary secondary contrasts are body_markers minus body_control (what the 3D observations add to encoder/cue) and full minus body_markers (what sorted signals add after the 3D observations). Report signed x/y bias and MAE, endpoint RMSE, trial counts, and separate bump and reach outcomes. Use a paired circular moving-block bootstrap over consecutive original trials (block length 12, 5,000 draws, seed 1641) for 95% intervals and family one-sided 97.5% upper bounds across the two planned secondary contrasts. Keep a trial’s paired epochs and windows together; contributions of missing strata are omitted rather than indexed across unrelated trials. An individual improvement requires its full tail average and the upper bound to be negative, plus lower average error in each epoch; no cross-animal or day-generalization inference. Correct-time/donor differences are additional diagnostics on their matched subset, not a new main gate. A filtered marker may contain information unavailable at the stated time in live use; the forecast is an offline association.
