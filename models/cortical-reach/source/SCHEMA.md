# Area 2 forecast source contract

The decoder accepts the one pinned local MATLAB member and the original split JSON by SHA-256. The public entry point is `build(mat, split_path, out, stage="train"|"validation"|"test", release_test=False)`. Test extraction additionally requires explicit study-owner release. NumPy and SciPy are required. Each stage emits its own NPZ and JSON trial audit. The membership JSON groups all 638 original IDs using previously frozen trial boundary and outcome metadata alone.

Each rewarded original contributes an attempted row for perturbation and voluntary reach at offsets 0, 5, 10, 15 (10-ms rows), in that order. Match separate sparse event arrays to the inclusive original interval. Require one bump, one target, one go, and bump strictly before both target/go. In the perturbation epoch require k+10 strictly earlier than both target and go. Reach anchors follow the recorded go and require target presentation at or before k. A direction is visible to predictors only when its event row is strictly earlier than the endpoint in question. Recorded row bins collect events at unknown within-bin times. This makes the anchor event invisible at offset zero, even though that event selects the example. Epoch, offset, trial ID, reward, absolute clock and future directions are never branch inputs. At present this session's valid compass directions are 0, 90, 180 and 270 degrees. A missing condition direction excludes that anchored example; a missing previously presented direction excludes that window. Unpresented cues give all-zero features. Never substitute the centre-hold bump flag for the event.

Use the original MATLAB one-based row k for all exports, with no intertrial padding. The horizon is p[k+10]−p[k], in encoder centimetres. History consists of five 40-ms tokens in chronological order. For token edges e = k−16,k−12,k−8,k−4,k, its spikes are from the four completed 10-ms rows e−4 through e−1 and its movement features are p[e] and p[e]−p[e−4]. Require the 21 history position rows and forecast endpoint finite, and all 20×30 sorted-count cells nonnegative, finite and integer. All 20 past rows and both displacement endpoints must remain in their own original trial. Checks use the stored 10-ms clock. The archived encoder pipeline can filter bidirectionally and camera processing may interpolate or smooth across rows. The six queried marker endpoints produce optional secondary features; gaps in them never remove primary windows. No archived velocity enters.

| NPZ key | Shape and interpretation |
|---|---|
| trial, epoch, offset, k | N rows. Epoch 0 perturbation; 1 reach. Offset in 10-ms rows from actual bump/go |
| original_trial | Every rewarded original assigned to this block in chronological order, including entirely excluded originals |
| movement | N×5×4. End x, end y, within-bin dx, within-bin dy, all cm |
| neural | N×5×30. Spike counts per four rows, exact MAT positive-sort column order; 52 unsorted columns excluded |
| unit_guide | 30×2. Source (electrode, sort ID), meaningful only for this animal/session |
| cue | N×5×7. Bump seen, cos, sin; target seen, cos, sin; go seen. Each indexed separately at its bin endpoint |
| observed_direction | N×2. Visible bump/target direction in degrees at k, NaN for unknown; descriptive, not model input |
| y | N×2. Subsequent 100-ms handle displacement x,y in cm |
| cv | N×3×2. Forecast in cm using constant velocity from k−4,k−10,k−20 respectively to k, projected 100 ms ahead |
| marker, marker_valid | N×5×12. Endpoint XYZ of Marker_3 (hand landmark) then Pronation_Pt1 (elbow landmark); six matching within-bin changes. Shoulder-relative coordinates in recorded XYZ order, metres. Boolean mask has identical shape. Gaps stored as NaN. A finite value describes the released processed grid, not original frame visibility |
| donor | N. Index within this same split; −1 for no earlier match. Choose most recent earlier different original with same epoch, offset and exact known cue flags and directions at k. Register donors only after all windows for the current original. Donor uses that row's already-completed sorted counts. Future directions and test labels never enter matching |

Immutable input, prior independent source review and pre-study membership establish that each sparse list is ordered, has at most one entry per original, and each rewarded original has one of each. Development extraction stops reading each event stream as soon as it reaches the first event in that block's final rewarded original; it never scans later sparse times. All three per-trial event lists and their multiplicities are recorded. Each attempted window appears in the audit with its retained index or exclusion reason. The centre-hold bump discrepancy in original 625 is retained as flag metadata and will be verified on authorized test release.

The day is C_20170912_COactpas_TD only. There are 324 train, 108 validation, 108 later test rewarded originals; 97 A and one I stay outside these. The prespecified demo is original 499, the first original in that held block. Only after release, demo.json retains the duration of that original, all ten processed shoulder-relative XYZ paths in source order, sorted counts, measured planar handle, actual event bins and elapsed seconds relative to trial start, observed direction metadata, and each forecast anchor or exclusion. Clinical, language, causal, multi-animal, across-day and online interpretations are unsupported.
