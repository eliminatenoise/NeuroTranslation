# Does an anatomical simulation improve a forecast of measured movement?

Use the previously analyzed reach study's three immutable source and OpenSim-length archives, reused for a new retrospective conditional-input comparison. The acquisition contains a real recording of hand and upper arm markers, planar movement of the handle, and spike counts. The 39 muscle–tendon paths come from the authors’ arm geometry applied to the tracked pose. Only the lengths anchored at k−1 are eligible inputs. The reference outcome is the instrumented handle's x/y displacement k+9 minus k−1, in millimetres. No later estimate of a muscle length enters any model input. This tests the additional usefulness of the named modeled lengths at the last observed time. Force and EMG were not measured in these path arrays.

Use all earlier 519 registered windows for fitting, with one total vote per original trial within each workspace then equal weight per training workspace. Use all eligible rows in each of the two later recording blocks. Score both original physical workspaces with equal original-trial weight using (block, original) identifiers. Check source identities and map all 39 geometry columns by name. Movement predictors are last observed pose across all eight positions and last-minus-prior offsets at 4, 9 and 19 bins, totaling 32 features. Use native pose units before training-set standardization. When supplied, cortical predictors are the 37 matched acquisition-contact counts summed across sort labels, at each of four consecutive five-bin intervals in the prior history. The contact map can match a hardware site across days without identifying a stable neuron. Retain body-only and neural-plus-body baselines.

Fit identical multivariate ridge models with one weight per original and an unpenalized intercept. Add 39 columns for every model. For each information baseline, compare three alternatives at the same feature dimension: a zero geometry vector, the actual 39 modeled muscle–tendon anchor lengths, and the frozen same-fit evaluation with an anchor borrowed from the latest earlier distinct original trial in the same workspace and block. Disclose scope of control and donor gaps. Standardize training features by weighted source mean and population SD (constant features have scale one); fixed slope penalty 1. Use the same model complexity and all other features for each comparison. Fit an additional persistence forecaster. Report held endpoint Euclidean mm errors, paired differences and coverage by workspace on the identical rows that have an eligible donor, and all-available errors. Support for adding model-derived muscle geometry requires lower error versus both the geometry-free fit and the wrong-anchor control in *both* physical workspaces, for the neural-plus-body comparison. No causal or between-species claim. Existing prior reports provide distinct direct EMG and movement-ground-truth tests; do not turn muscle-path estimates into measured activation or force.
