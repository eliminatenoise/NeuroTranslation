# Forecast the angular velocity of a moving cylinder

The input is a single wearable instrument's own recording: twenty successive acceleration and gyroscope samples immediately before a cutoff. Its acceleration includes gravity. For each group of four samples use the last and mean three-axis reading of the gyroscope, then the last and mean three-axis reading of the accelerometer. Append the end time of that group in seconds, a two-entry hand indicator and eighteen hand-by-target indicators. The target is supplied to the software from the task assignment; the precise time at which it became available to the person is unresolved.

Fit one small neural network per input condition and seed. A linear projection into 16 numbers and five learned temporal position embeddings feed a two-head dot-product attention block, a 32-unit ReLU feed-forward block, residual connections and two layer normalizations. The last token predicts six continuous components. Three are the next 100 ms mean angular velocity in rad/s; the other three are mean acceleration in m/s², including gravity, all on device axes. Each task is centered on its three training-axis means and scaled by one training RMS deviation across its three components (floor 0.0001 in its native unit). Standardize the twelve sensor token features and time using only the fitting partition, retaining the raw 0/1 hand and target indicators. Cap normalized sensor/time inputs at ±10 for every arm. Scaling and every model receive equal original-recording weight inside each participant, then equal participant weight. Each participant's valid originals and each original's valid windows share its weight.

The five matched arms read all fields, gyro plus task cues, acceleration plus task cues, sensors without a destination and task only. In each, the omitted standardized channels are set to zero. Hand and elapsed time are always available. A sixth fit uses full input and optimizes only gyro output; its unused acceleration readout is never scored. Seeds 17, 41 and 73 have the same starting parameters across conditions, a seeded order for every complete pass, 20 passes, batch size 256, AdamW learning rate 0.0015, weight decay 0.001, gradient norm cap 1. Both task losses carry equal weight in the shared model. A second family of weighted ridge regressions fits all five input combinations using the same five time tokens flattened in order, a free intercept and slope penalty 0.01. No validation or later-trial normalisation, refitting, temperature or threshold selection.

On the earlier training repetitions qualify CPU one/two threads and available ROCm using an identical 32-update prefix and 64 probe histories, separately timing complete subprocess execution. Retain CPU1 unless a different backend has max absolute gyro and acceleration delta ≤0.0005 in each native unit and at least 10% lower elapsed time. This is baseline qualification on a bounded prefix. Reconfirm portable NumPy inference on actual runs; future platform precision may differ.

The primary quantity is Euclidean miss in the three-axis mean angular velocity in rad/s. Compare full minus gyro-and-task and full minus wrong acceleration. For wrong acceleration, retain the true gyro, visible assignment and time; substitute acceleration from the nearest strictly earlier qualifying registration in the same split and participant/hand/target/cutoff. Both differences must have upper paired 95% limits below zero on common held windows. Group by original and person, preserving all windows and wrists of a person. Use 10,000 participant draws with replacement, default_rng(20261124). Calculate each seed's errors before averaging. A full original early gyro/accel vector enters the model as feedback; these are data forecasts, not a closed-loop intervention. Report secondary acceleration, shared versus gyro-only training, task-only and simple baselines separately. Naive persistence uses the last 10 completed samples; trend adds the difference between the most recent and preceding 10-sample averages to that most recent mean. A conditional hand/target/time mean is fitted on earlier originals, weighted equally across people within each cell.
