# Does a rate forecast predict an observed change of orientation?

This secondary component was designed before the inertial validation and held repetitions were numerically released. Keep all frozen main-study comparisons intact. The gyroscope reports how quickly the sensor rotates about its own axes. The same instrument supplies an estimated orientation quaternion (scalar first, sensor to local Earth frame). The projected angular increment and physical display are useful only insofar as this convention can be checked from the source. This is a comparison to the instrument's own orientation estimate, not independent optical ground truth, translation, or human joint rotation.

Use exactly the original eligible windows on the 100 Hz instrument clock. Let q0 be the last genuinely observed input orientation (k−1) and q1 the orientation at the end of the ten-row outcome (k+9). Unit-normalize only finite quaternions with original norm within 0.01 of 1 and retain failures as excluded. The future 0.1 s angular rate forecast is a single 3-vector in sensor axes. Predict q1 by right-multiplying q0 by the unit quaternion with rotation vector 0.1 times the predicted 3-vector. Use geodesic angular error in degrees, 2 acos(|dot|), stable for q and −q. Compare on common matched support full, gyro+task, wrong accelerometer, gyro-only-loss, true gyro history persistence, full ridge, and held-orientation (zero incremental rotation). Preserve seed-by-seed errors. Equal sample weighting inside original, then equal originals within participants and equal participants; use the original seed 20261124 and 10,000 paired participant resamples. Record category support and results by hand and cutoff. A descriptive future-gyro integration uses all ten observed per-sample rate vectors with 0.01 s increments and the sensor-axis product ordering. It is unavailable at the input cutoff and must never be counted as a predictor. Native quaternions can contain onboard sensor fusion, so discrepancies need not be timing errors. Report whether any rotation forecast improves over both the held-orientation and persistence baselines on these sampled repetitions, with paired uncertainty; do not use this secondary measure to change the primary gate.
