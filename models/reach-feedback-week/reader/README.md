# A reach, one week later

Extract the whole ZIP before opening it. Double-click **index.html** in the extracted **one-week** folder. The Windows, macOS and Linux launchers beside it open the same reader in your default browser. Use a current browser with JavaScript enabled. Every forecast, recording excerpt and result runs locally. The reader needs no installation, server, account or network connection. External links to the paper, 3D atlas, source data and same-day study require a connection.

Select a recording and an electrode contact. The early forecast uses 200 ms of past measurements. The updated forecast takes the next 100 ms of measured movement and predicts counts over the following 100 ms. The chart and tables show the observed values. Opening **Change a path and run the models** lets you change a hand, elbow or handle coordinate. The data tables accompany every plotted curve. Restore the recording to compare the forecasts with the observed outcomes again.

The three contact populations have separately fitted coefficients. The fourth comparison also conditions both arms on the intervening spikes. The fitted movement line runs all three day-one movement models on your selected earlier path, cues and counts. Changing only the newly observed path alters the count update while leaving that earlier movement forecast in place. Counts are expected events per contact, so they can be fractional. The shaded area of the movement plot marks the ten new samples.

See [Attribution and methods](NOTICE.md) and the machine-readable [results](results.json). **SHA256SUMS** lists every other file's SHA-256 checksum in the release directory. Source code and learned model coefficients are included in the package.
