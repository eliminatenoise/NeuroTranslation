# Forecasting recorded object displacement

The dataset places nine targets around the same starting location. For each hand separately, we kept each participant’s first two assignments of each target before applying optical exclusions. The development set contains 24 people and includes 824 usable trials for both clocks. Seven different people supply the assessment sample. The source numbers were ordered by age; every fourth number is reserved. Each clock can exclude trials for missing input or outcome, with counts retained in the source and results folders.

Take the first optical positions at or just before 0, 50, 100, 150 and 200 ms relative to the chosen reference. Future outcomes use the first valid source position at or just after 400, 600 and 800 ms with a maximum tolerance of one native 250 Hz frame. For each later position subtract the last input position. A fixed set of available markers, chosen in the first usable optical frame, determines the tracked centre throughout the trial. Digitized coordinates come from the unrotated optical frame. They do not establish anatomical axes. Upstream optical processing may have filled gaps using information from later frames.

Five time tokens carry relative XYZ, change from the previous point, sample time, hand and the hand-by-target category. The full Transformer reads all fields. The pose-only arm blanks the target, and the goal-only arm blanks the position and motion channels. Hand and time are common. The network projects to width 16, then uses a two-head attention layer and a width-32 feed-forward layer with skip connections and layer normalization. A final linear readout returns nine displacement components in metres. Each arm uses the same 40 passes, seed-specific initialization and ordering, batches up to 64, AdamW at 0.0015 and a gradient norm cap of 1. Three independent seeds are 17, 41 and 73. The three ridge regressions use the same inputs and a 0.01 penalty on slopes. All position scales, target scale, weights and mean paths are derived from the relevant development set. Training gives each participant equal overall weight within a supported horizon. The data are small enough to reproduce these fits on a CPU.

For a wrong-destination comparison, give the same frozen full model the same early history and hand, and request all eight other targets. Compare each of those eight forecasts to the original measured outcome and average their errors. These are counterfactual software inputs; an individual’s motion to another target under this identical history has not been observed. Separate baselines hold the object stationary, continue its last measured velocity, or use the development mean by hand and target.

Score each forecast by Euclidean endpoint error in metres. Average trials within each person, then people and individual seed errors. For paired 95% intervals, draw seven held participants with replacement 10,000 times using seed 20261122. A destination benefit at 600 ms requires both the full-minus-pose-only and full-minus-wrong-destination intervals to fall wholly below zero. The 15 mm crossing comparison is secondary; it uses its own training set and applies only to supported movements. Neither clock passed both tests. Seven people from one study limit how broadly the measured performance can be applied.
