# Reproduce the forecast

All paths below start in the extracted folder containing the two directories `shared-motion-model` and `shared-motion-data`. Forecasts require Python 3 and NumPy. Fitting also requires PyTorch. The recorded training environment used Python 3.13, NumPy 2.5.3 and CPU PyTorch 2.14.1. The source conversion uses the packages specified in the data guide. Version and archive differences can change floating-point results or file hashes. [Data guide](../shared-motion-data/README.md) · [Runtime record](execution.json)

## Inference

```sh
python shared-motion-model/run_examples.py
python shared-motion-model/predict.py shared-motion-model/reference-examples.json
```

The NumPy implementation loads arrays with `allow_pickle=False`. Its default file, `shared-weights.npz`, has SHA-256 `9a3649cb8f2119984e7f9f0b96a07bdc95e1833c7068f0e9caef2680f22e3179`. The NPZ contains named weight arrays and a JSON configuration. Use `SharedMotion.load(path)` in Python to load the same state into PyTorch. Both code paths calculate full attention over the four intervals, which all precede the forecast.

## Restore the admitted records

The restore command downloads hash-checked files from the project’s pinned public benchmark release and the original HoloAssist member ranges. Use the complete data guide for package versions and source requirements. Give the extracted scripts a writable `reconstructed` folder. They fetch only the named role.

```sh
python shared-motion-data/restore.py train --root reconstructed
python shared-motion-data/prepare.py train --root reconstructed --workers 1
```

Retain the original train and assessment packet receipts generated by `prepare.py`. The fitting code checks the exact training hash and its role receipt before learning. If reproducing the study prospectively, complete fitting before restoring the assessment records.

## Fit and score

Use one CPU process with `OPENBLAS_NUM_THREADS=1`, `OMP_NUM_THREADS=1` and `MKL_NUM_THREADS=1`. The command below explicitly sets the PyTorch intra-op thread count to one. It always sets the inter-op thread count to one. It writes a new output directory. The study made no validation-based hyperparameter or epoch choices. [Frozen method](protocol.json)

```sh
python shared-motion-model/train.py --threads 1 --out reproduced-fits
python shared-motion-data/restore.py assessment --root reconstructed
python shared-motion-data/prepare.py assessment --root reconstructed --workers 1
python shared-motion-model/score.py --fits reproduced-fits --out reproduced-local-results
```

To score the shipped comparison weights directly on the restored assessment packet, use `--fits shared-motion-model/fits`. Per-window predictions produced by scoring and per-recording source files belong in the local reconstruction. For a local recorded reference, run `python shared-motion-model/examples.py --out invented-examples.json --local-recorded private-recorded-examples.json` after restoring the train role. It selects the first retained window in each training domain. The public examples use two invented histories.

For each training seed, the five arms start from the same parameters and receive 400 updates. The shared model sees 32 wrist and 32 rat examples per step. The first single-domain comparison sees exactly the same 32 examples of its own domain as the shared model on every update. The second sees 64 examples of its own domain and matches the total number of examples processed. All fits randomly draw a group then a row within it, with replacement. A small number of repeated training examples supply many updates, particularly for the rat, which has only 188 distinct windows. Each domain has its own output row. An unused output row remains in single-domain model storage for a matched architecture.

The shared encoder gradient from each domain is recorded after one update, when the initially zero output weights have begun to change. Each domain's loss reaches the same attention matrices and its own output row. Group sensitivity estimates come from 10,000 paired resamples of recording groups for the wrist and circular blocks of three consecutive trips for the rat. Group dependence, one rat and repeat examination of the cohorts limit inference. [Fit hashes](fit-seal.json) · [Public aggregate scores](summary.json)
