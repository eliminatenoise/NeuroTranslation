# Read the fixed-pedal recordings

A seated volunteer pulls the forefoot upward against a fixed pedal. A skin electrode records electrical activity over the shin muscle that helps lift the foot, the tibialis anterior. A sensor under the pedal records the load on the platform. The two channels share a recording board. These files let you ask whether recent muscle activity helps predict the next change in the load reading. [Study methods](https://doi.org/10.1038/s41597-024-04285-x)

Run the extractor with Python 3.11 or newer, NumPy and SciPy. It retrieves the selected MATLAB files from the BioImage Archive and writes the original and a small NumPy archive for each trial. The first command reads the eight training recordings from A01 and A02. The second reads the eight selected assessment originals from A03 and A04. The first run needs internet access. On later runs it verifies the original bytes already in the cache. [Data and licence](RIGHTS.md)

```sh
python -m pip install numpy scipy
python extract.py development --cache ankle-pedal
python extract_assessment.py --cache ankle-pedal
```

The study selects two trials per person at a level pedal and two at the other selected setting. The archive distinguishes `angle5` from `angle_5`. This study uses the literal `angle5` category. The source material reviewed here does not specify which five-degree filename corresponds to a toe-up or toe-down pedal. The filename records the instructed setting. A time-varying ankle angle would require a separate measurement. [Task 1 archive](https://ftp.ebi.ac.uk/biostudies/fire/S-BIAD/482/S-BIAD1482/Files/ScientificData/Task%201/)

Inside each `.npz`, `emg` represents the original `emg_1` signal and `load` represents `loadcell_right`. Eight development files and four assessment files carry both signals on the original recording rows. Three more assessment recordings include the authors’ stored copies on a slower grid. Their numbers remain in native acquisition units. The authors describe an amplified electrical signal and a load conditioner with a voltage output. Determining force in newtons would require the measured voltage-to-force gain and offset. The word “right” belongs to a channel name. Participant limb laterality cannot be read from it. [Task 1 procedure](https://ftp.ebi.ac.uk/biostudies/fire/S-BIAD/482/S-BIAD1482/Files/ScientificData/Task%201/Manual%20labeling/mycom%20of%20PA%20and%20EMG.m) · [Measurement apparatus](https://doi.org/10.1038/s41597-024-04285-x)

The third array, `time_s`, labels positions within one trial. In the accompanying `.source.json`, `stored_regular_vector` means the file contains a regular time vector. `sample_index_at_published_1000_hz` means the file omits time and the labels count rows from zero at the published rate of 1,000 samples per second. In either case, 100 rows represent a *nominal* 100 milliseconds. The recordings supply no independent hardware timestamps for checking jitter. For files without time, missing hardware samples also cannot be detected from these generated labels. The source note gives the field names, stored-time checks, finite sample count, trigger spacing and original fingerprint for each trial. [Study methods](https://doi.org/10.1038/s41597-024-04285-x)

A03 shows why the two recording grids matter. Three files contain 60,001 pairs of raw measurements on a stored 10 kHz clock. The authors also saved 6,001 pairs at 1 kHz. The assessment extractor checks that every time, muscle and load value in that copy equals every tenth original item, from the first through the last. It writes those saved copies to the analysis files. A04 supplies four regular 1 kHz recordings of 7,001 rows each. [Assessment source fingerprints](assessment-manifest.json)

A03’s first level-pedal trial supplies 110,001 rows and two columns under the right-load name. It supplies neither a stored time axis nor the matching 1 kHz copies. The second column changes state four times from low to high. The separate trigger has 10,001 rising edges. Those patterns do not identify a load column and its sample rate together. The assessment command keeps the verified original and writes a source note explaining why that trial has no analysis array. Seven of the eight assessment recordings yield paired data. Both repeated trials are available for A03 at `angle5` and for A04 at both settings. [Assessment source fingerprints](assessment-manifest.json)
