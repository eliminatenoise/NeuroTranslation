# AnkleImage data and credit

Qiang Zhang, Noor Hakam, Oluwasegun Akinniyi, Ashwin Iyer, Xuefeng Bao and Nitin Sharma released *AnkleImage – An ultrafast ultrasound image dataset to understand the ankle joint muscle contractility*. The BioImage Archive lists the dataset as CC BY 4.0. Keep the authors, dataset title, source link, licence and description of changes with redistributed data or adapted figures. [AnkleImage, S-BIAD1482](https://doi.org/10.6019/S-BIAD1482) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [Data descriptor, Scientific Data **11**, 1439 (2024)](https://doi.org/10.1038/s41597-024-04285-x)

The extractors select two channels from Task 1, preserve their order and values, and write both as one-dimensional arrays. Three assessment recordings use the authors’ saved 1 kHz copies after checking every value against every tenth row of the original 10 kHz recording. One assessment source has ambiguous columns and timing and is retained without an extracted pair. It copies the stored time labels when available. For files that omit time, it creates a nominal elapsed axis from the sample positions and the rate the authors report. The manifests identify each original MATLAB file by its archive path, size, HTTP ETag and SHA-256 fingerprint. Every usable recording also has fingerprints for the three extracted arrays as little-endian 64-bit numbers.

The original Task 1 procedure uses `emg_1` and `loadcell_right` on a common index and constructs its time grid at millisecond intervals. Its archived file has SHA-256 `dfc24040c015ac4ac8bcd08e6a5de5754c68366639fbce797ab127922c1258cd`. The authors’ script and the original recording files are available from the archive. The article is published under CC BY-NC-ND 4.0. The package links to the article for its methods.
