# Does the walking instruction help?

Extract the entire ZIP. Open `index.html` in a browser, or choose the launcher for Windows, macOS or Linux. Keep the files together. The forecast runs on the device without an internet connection, server or package install. Links to the paper, recorded gait and shared-model controls open online.

Select either walking instruction or withhold it. The table gives the pelvis and right heel’s signed forward, left and up displacement 100 ms after cutoff. Change the chart axis to see the same forecast beside the preceding 200 ms of invented movement. Adjust the assumed pelvis speed, heel lift or strike timing to generate a different invented history. The example has no observed future.

Both phrases select the same fitted Transformer, with opposite values of one task code. Withholding the instruction selects a separately trained motion-only model with equal capacity. The recorded-walk results show when the correct cue helps against each control. The data contain two protocol instructions and marker motion. They provide no recording of anyone speaking and no neural signal.

The code in `predict.js` runs the fits embedded in `weights.js`. The coordinate signs and landmark order appear on the page. The summary tables and `results.json` give aggregate errors and uncertainty for both evaluation groups. See `NOTICE.md` for the original data and license. Files listed in `SHA256SUMS` can be checked after extraction.
