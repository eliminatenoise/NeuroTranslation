For a Linux application-menu entry, extract the ZIP and run sh Install-NeuroTranslation-Linux.sh in that folder. It installs one per-user entry, prefers Omarchy when available and opens no browser during installation. It preserves any different file already using its managed name. This is a data inspector and alignment tool. No trained NeuroTranslate model or model backend is connected. R11 manuscripts and the portable interface are source-only previews; no weights or runnable model download are included.

These launchers open online previews. They do not contain an offline game, trained model or missing backend. Windows/macOS native opening has not been tested here; static format checks do not establish all operating-system or browser behaviour.
