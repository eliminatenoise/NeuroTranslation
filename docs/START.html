Keep a launcher on your computer

These shortcuts open Palm replay in your browser and need a network connection. If a shortcut opens as text, extract the ZIP first. Keep the filename extension and follow your system’s normal opening prompts.

  • Windows launcher
  • macOS launcher
  • Linux launcher
  • Linux menu installer
  • All launchers ZIP

For a Linux application-menu entry, extract the ZIP and run sh Install-NeuroTranslation-Linux.sh in that folder. An existing entry may open the preview. Choose Palm replay there. The installer preserves existing entries and customizations and opens no browser.

Windows and macOS shortcut formats and isolated Linux installation were checked. Native shortcut opening on Windows and macOS remains unchecked.
