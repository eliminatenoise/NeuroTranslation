NeuroTranslation

Vertebrate neural recordings

An electrode picks up electrical impulses. Spike sorting can assign those impulses to individual cells. A camera can follow changes in calcium fluorescence across a fish’s brain. Both record neural activity, but they answer different questions. These 15 deposits show what was measured, which files were checked and where a prediction was tested.

Which recorded unit spikes next?

Spike sorting assigns detected electrical events to local clusters called units. Five coefficients fitted on one rat’s spike history were applied to other recordings with their own unit labels. Each forecast ranks the units for the next millisecond that contains a spike. Bins with multiple target spikes have no single scored identity.

Rat · hippocampus and prefrontal cortex

The original study tested later trips from the training rat and trips from a second rat. The second recording had 122 candidate units. A running count almost matched the fitted model’s first-choice accuracy.

Read the two-rat study

Turtle · dorsal cortex

In one recording during visual stimulation, the fitted model assigned better probabilities than running counts across 6,978 scored transitions. Log loss was 3.992 against 4.044, where lower is better. Giving each target cluster equal weight reversed that comparison. The archive gives each cluster a local label with uncertain single-cell identity.

Read the turtle analysis

Salamander · isolated retina

Three visual stimuli supplied 34,490 scored forecasts from sorted retinal ganglion-cell spikes. A rule that favoured recently active cells beat the rat fit for every stimulus. Giving each stimulus equal weight, log loss was 4.419 for that rule and 4.507 for the fitted model. The archive does not identify an animal for each experiment.

Brown ghost knifefish (Apteronotus leptorhynchus)

Electrophysiology

Electrosensory afferents, hindbrain and midbrain in separate recordings. Afferent single recordings, simultaneously recorded pairs, and central electrophysiology. The listed sample is the hindbrain archive.

Source check · hindbrain ZIP member directory inspected.

Data deposit · Original study
Recording conditions and reuse

Responses to weakly electric fish communication signals (chirps) presented at different phases of a background beat. Event and stimulus clocks must come from each file’s documentation.

A list of single-cell recordings does not form a simultaneous population. Recording type and timing determine the valid target. Distinguish simultaneous afferent pairs from cells recorded at different times. Group all trials of each recording, then by animal where IDs are recoverable.

Zebrafish (Danio rerio)

Fluorescence imaging

Forebrain in larval zebrafish. Two-photon fluorescence imaging, including the neural calcium indicator GCaMP6s and a fluorescent cell-type marker.

Source check · NWB imaging-series shapes inspected.

Data deposit · Fluorescence forecast results
Recording conditions and reuse

Random-wave temperature stimulation in larvae. Read each series’ imaging clock and optical-channel metadata before assigning an indicator or sampling rate.

Indicator fluorescence integrates neural activity over time. Extracted or deconvolved calcium events would be inferred quantities. Eight fish listed. Keep both channels, all optical planes and all sessions of a fish together.

Larval tiger salamander (species epithet unspecified in the cited methods)

Spike times

Isolated retina, ganglion cells. Extracellular array. Sorted ganglion-cell event times.

Source check · archive member directory inspected.

Data deposit · Original study · Spike forecast results
Recording conditions and reuse

Four visual protocols include repeated and unrepeated movies, white-noise checkerboard and a moving bar. Acquisition sampled at 10 kHz. Check the native MAT time units separately.

The sort supplies recording-local labels. Equal timestamps need a tie rule. An observed unit set covers only part of a retina. Keep each preparation and stimulus run together. Never assume that cell indices align across retinas or protocols. A repeated movie can leak stimulus identity across trial splits.

Binned spikes

Isolated retina, ganglion cells. Extracellular spikes curated by template sorting, released as binary activity per cell per bin.

Source check · provider documentation and asset listing.

Data deposit · Original study
Recording conditions and reuse

Five 20-second natural movies with at least 80 repeats each. The source reports 16.667 ms bins and 93 cells.

Multiple cells can be active in the same bin. Their sub-bin firing order is lost. Group by retina, movie and repeat. This release describes a single retinal preparation. Two deposits with overlapping authorship do not establish independent animals.

African clawed frog (Xenopus laevis)

Cell voltage or current

Optic tectum in developing tadpoles. Whole-cell recordings. The current-injection folders contain single-neuron membrane voltage. Voltage-clamp folders contain currents.

Source check · individual MAT variable directory inspected.

Data deposit · Original study
Recording conditions and reuse

Step and cosine current injections, optic nerve stimulation, and spontaneous miniature currents have distinct protocols. Use sweep timing and command waveform for the chosen cell.

A single patched cell has a physical identity for a sweep. Separate cells are not a simultaneously observed population. The master file maps sweeps to a cell ID. Group all sweeps from one cell, then by animal where a mapping is available. Without animal IDs, report cell-level generalization only.

Public deposit. Use the file link on the landing page. The Dryad download API can require a bearer token.

Ciarleglio, Khakhalin, Wang, Constantino, Yip, Aizenman. Data from: Multivariate analysis of electrophysiological diversity of Xenopus visual neurons during development and plasticity. Dryad, 2016. · CC0-1.0

Turtles 1 deposit

Red-eared slider (Trachemys scripta elegans)

Spike times and field potentials

Dorsal visual cortex. Two distinct products. Downsampled local field potential (LFP) and derived components, plus figure data with cluster-labeled spike timestamps.

Source check · author MAT and raster code inspected.

Data deposit · Original study · Spike forecast results
Recording conditions and reuse

Behaving turtles saw a visual oddball sequence while their eyes and heads were tracked. The raster code uses milliseconds. Its 200 stimulus onsets are sorted by condition.

109 distinct cluster labels occur in the inspected array. The label count does not certify 109 well-isolated neurons. LFP and its principal components contain no cell IDs. Use recname and the animal-to-session mapping where available. Restore true time from onset values. The inspected spike example represents one recording.

Birds 2 deposits

Zebra finch (Taeniopygia guttata)

Threshold crossings

Song motor nucleus RA (robust nucleus of the arcopallium). Neuropixels channel threshold crossings and microphone audio. Broadband voltage is a separate companion deposit.

Source check · NWB dataset shapes inspected.

Data deposit · Original study
Recording conditions and reuse

One bird sang across multiple days. tx stores threshold crossings on the 30 kHz acquisition clock, and the benchmark target is an audio spectrogram.

The 85 tx columns in the inspected file index recording channels. Threshold crossings do not individually identify neurons. One animal. Hold out sessions/days and keep song renditions intact. The three archive subject labels encode benchmark splits. Minival repeats a subset of calibration trials.

Public archive. Draft collection. Pin the asset identifier and digest.

Rock pigeon (Columba livia)

Visual response summaries

Anterior entopallium, a visual forebrain area. Extracellular channel responses to images. The paper describes mainly multi-unit recordings, a further isolation-quality subset, and repeated responses averaged for its analysis.

Source check · response dictionary inspected without executing pickle.

Data deposit · Original study
Recording conditions and reuse

Sixteen anesthetized pigeons viewed images of objects with variations in category or viewing angle. The primary analysis used mean response 50–500 ms after stimulus onset.

The checked file has experiment/channel response keys. It offers no demonstrated single-neuron event stream for a next-unit test. Keep channel records with their experiment and bird wherever mappings are documented. Separate objects or categories when testing visual generalization. Never count channels as animals.

Public Figshare deposit. Both neural dictionaries are separate from the stimulus photographs.

Zhu, Juncai (2025). Neural Representation of Object Category and Viewpoint in the Entopallium of Pigeons. figshare. Dataset. https://doi.org/10.6084/m9.figshare.30406729.v1 · CC-BY-4.0

Cortical surface voltage

Clinically selected intracranial cortical surface electrodes. Implant coverage varies by participant. Electrocorticography (ECoG), synchronized with video-derived upper-body joint positions.

Twelve participants during natural inpatient activity over 55 semi-continuous days in total. Wrist movement events and pose estimates accompany continuous neural recordings.

One ECoG contact records a local aggregate voltage. The accompanying pose estimates provide no individual-neuron label. Hold out whole people for cross-person evaluation. Human (Homo sapiens)

Spike times

Medial temporal lobe, including amygdala and hippocampus. Microwire recordings with sorted extracellular units. The NWB release includes a Units table.

Source check · provider documentation and asset listing.

Data deposit · Original study
Recording conditions and reuse

People undergoing intracranial monitoring viewed images and made recognition-memory judgments. The deposit reports 59 participants. Read event clocks, observation intervals and simultaneous unit membership within each session.

These source-local unit labels support a candidate event target once clock, quality and simultaneous membership are verified. They do not map a cell from one person to another. Group repeated sessions by participant. Check for duplicate recordings or reused stimulus images across partitions before reporting a cross-person result.

Human (Homo sapiens)

Scalp voltage

Scalp over the head, 10–10 EEG electrode montage. 64 electroencephalography (EEG) channels plus EDF+ event annotations.

Source check · EDF+ header inspected, zero waveform samples read.

Data deposit
Recording conditions and reuse

The archive describes 109 volunteers and 14 runs per participant, including actual and imagined fist or foot movements. EEG sampled at 160 Hz. Cue labels depend on the run.

Each scalp channel sums activity from many sources and contains artifacts. Neither electrodes nor cue codes designate neurons. Hold out whole participants. Keep trial windows together and never mix imagery, execution and baseline when assigning the motor label.

Open PhysioNet release. The data page requires attribution under the Open Data Commons Attribution License v1.0.

Schalk and colleagues. EEG Motor Movement/Imagery Dataset. PhysioNet, version 1.0.0. · ODC-By-1.0

What could a fly or worm contribute?

FlyWire traces connections in a fly brain. Reconstructions of worms at different ages show how their wiring differs across development. They can suggest which connections to test. Predicting activity in a vertebrate requires a separate experiment on a vertebrate recording.
