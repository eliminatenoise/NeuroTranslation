# What will the glove read next?

Open **index.html** in a browser or use the launcher for Windows, macOS or Linux. The page works offline. **Save offline** makes another standalone copy that opens on the original invented example.

A glove has one sensor for each finger. Two models fitted to an earlier recording guess the five readings 120 milliseconds ahead. One model uses the preceding four glove readings and the finger cue on the screen. The other also receives two bands of electrical activity from electrodes on the surface of the brain. Holding the last reading supplies a third forecast.

Choose the **finger cued on screen** to change the instruction while keeping the five invented glove histories. Choose **glove readings** to hold each sensor steady or have them rise. Move **cortical band power** to change the electrical input while leaving the glove and screen alone. Only the model that uses the brain signal responds to that slider. The fixed hand diagram locates the five sensors. The chart shows the cued finger and the table gives all five forecasts in raw sensor counts. These examples have no measured future value or calibrated joint angle.

## What happened on recorded trials?

Fifty-two trials from one recording supplied the fitting data. The comparison used 23 later trials in the same development recording. Holding the last reading gave the smallest normalized mean absolute error, 0.1774. The glove-and-cue model scored 0.2502. Adding brain activity raised that error to 0.2849, with larger errors for all five fingers. The paired gain, glove-and-cue error minus error with brain activity, was −0.03470 (95% within-record interval −0.04630 to −0.02396). With the same fitted weights, the gain for correctly paired brain activity over an earlier same-cue trial’s activity was 0.00426 (−0.00061 to 0.00897). The lower bound of each contrast had to exceed zero for the study to find an advantage.

Raw error is the mean distance between forecast and measured glove counts. Normalized error divides each finger’s mean error by its training target standard deviation before averaging. The intervals used 5,000 samples of consecutive three-trial blocks. The 68 forecasts in each trial overlap. Only one later trial cued the little finger. The result applies to this one recording and these models. Alignment was on the released file’s nominal grid. Hardware-level synchronization, live availability, transfer to another person and physical actuation remain unverified.

## Rebuild the offline page

In the repository, run `python -B build.py` from `docs/finger-signals/` using Python 3 with NumPy. The default input is `../../models/cortical-glove/`. In a different layout, pass `--model PATH_TO_MODEL_FOLDER`. Use `--out PATH` to write a separate copy. The builder checks the eight study-file digests in `src/inputs.sha256.json` and the local rights copies. Only the two ridge parameter sets, four invented glove readings and four synthetic signal summaries enter the browser. The recorded results appear as fixed aggregates.

The four input times are −120, −80, −40 and 0 ms. The screen shows a finger cue throughout, with 920 ms elapsed at the cutoff. The model fits standardized input columns and adds its predicted changes to the last observed glove values. The original invented example starts with 280 synthetic samples on each of 46 cortical channels. For each input time, the study’s feature extractor computes log-transformed band power in a trailing 160-sample window. The builder recovers the invented band powers and rounds them to 13 decimal places. The browser applies the power multiplier before taking the logarithm and running the fitted models. It retains full precision during prediction and displays tenths of a count.
