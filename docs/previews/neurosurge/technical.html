Movement preview

NeuroSurge plays the same simulation in Full and Lite. Both run the released NeuroTranslate 0.0 movement forecast in the browser. Lite transfers smaller anatomy files.

Play Full preview Play Lite preview

Use a desktop browser with WebGL, a keyboard and a mouse or trackpad. Open the standalone Movement mirror to run the forecast on its own.

Capture and command controls
  1. Press C. Choose Start camera to request video, or choose a local video or timestamped stills. Images stay on the device.
  2. Set Body follows for the arm or knee pose channels and Point to forecast for the marker. The ring shows its forecast position 120 ms after the last of five usable frames.
  3. Choose Save take and Open Command box to stop capture. Enter replay my take. F opens the Command box for supported moves such as “bend my right elbow”. In a browser with on-device dictation, choose Use voice and confirm the transcript.

Forecast accuracy on recorded movement

Constant velocity had the lowest mean endpoint error for each of three participants. Each participant performed a different movement, a walk, squat or shoulder press. The C1 and C3 views of each participant show the same recording. Person and movement are linked in this sample. The table averages each view, then both views per participant, then all three participants.

The exact released still-image detector and weights used five input frames. Constant velocity extrapolated the last two available positions by 120 ms. Endpoint error is Euclidean distance to the interpolated Vicon projection. Displacement error is the distance between the forecast change from the detected starting point and the Vicon change from its own starting point. The app's live comparison uses its own detector's later positions.

The run decoded 810 images for 1,086 scheduled time slots and scored 2,321 of 4,849 forecasts. The publisher's dropped-frame indices supply a nominal 60 Hz clock. An adjacent pair of valid reference rows must bracket the requested time. Missing brackets explain 2,524 exclusions. The publisher aligned Vicon and RGB frames after capture. Physical exposure times remain unverified. Only the squat recording supplied 23 shared comparisons across both views for all five shifts. Constant velocity had the lowest mean endpoint error across shifts of −2, −1, 0, 1 and 2 camera slots, about ±33 ms.

A separate jumping-jack pilot gave mean endpoint errors of 23.09, 28.03 and 23.82 pixels for holding position, constant velocity and NeuroTranslate, respectively, on 225 scored forecasts.
