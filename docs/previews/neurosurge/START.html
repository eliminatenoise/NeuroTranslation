Local play

Open the online movement preview to run the point forecast in your browser.

For offline play, download and extract the Lite ZIP. With Node.js 18 or later installed, open the launcher for your system in lite.

Local workbench and fingertip setup

  1. Extract the Lite ZIP. Download and extract the NeuroTranslate 0.0 ZIP. Put the extracted neurotranslate-0.0 folder beside the extracted game folder.
  2. Use Python 3.10 or later with NumPy installed. Open Play fingertip touch for your system in the game folder. Use Play movement mirror to start the game with the general local model.
  3. Open the local address printed in the terminal if the browser stays closed. Choose Play Lite. For the fingertip study, press F and enter forecast fingertip spikes.
  4. To open the checkpoint workbench directly, remove /game/ from the printed address and open that shorter address.
