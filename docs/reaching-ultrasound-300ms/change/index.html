Readings for your own forecast

Use arm positions and voltage readings from the same 20 ms window. The model reads four positions relative to the shoulder and voltages measured at the triceps, biceps and palm. It can also open a 26-column history from the spread forecast. It uses the first 22 values in each row.

Input fields and methods

Put ten rows under history, oldest first. A row covers 20 milliseconds. Use the same number of values in every row. Values 1–12 are the latest x, y and z positions for the hand, forearm, elbow and upper arm, in millimetres. Values 13–16 indicate whether each of those positions was measured.

Values 17–19 give the root mean square voltage, in millivolts, from the triceps, biceps and palm. Values 20–22 indicate whether each voltage was measured. An availability value of 1 means measured. Use 0 in both the availability and reading fields when a reading is missing.

The linear forecast fits a weighted sum of recent positions. The three learned forecasts repeat an internal update once or three times for each of two saved fits, then average their results. The rows marked “motion from start” subtract the first available position for each marker before calculating the forecast.

The forecast uses stored or invented histories. It leaves your camera off.
