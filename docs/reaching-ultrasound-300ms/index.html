      Forecast methods

      The simple reference follows the ultrasound trend if all five required readings are available for that muscle. It uses the latest five slots in the Complete setting and the oldest five after a gap. With a required reading missing, it uses the typical value from training.

      The linear forecast uses ultrasound alone in Complete, the older ultrasound with motion and muscle readings after a gap, and only motion when ultrasound is hidden. The learned forecast uses the readings available in the chosen setting.

      Use compatible, synchronized JSON histories for this model. The camera stays off on this page. Movement mirror tracks a point in the camera image and forecasts its position 120 ms later.
