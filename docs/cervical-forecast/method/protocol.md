# What can the early arm reading tell us about a later neck reading?

The target is electrical. For each recorded left median-nerve pulse, take the average SC6 neck voltage at 12 to <14 ms and subtract its average at −15 to <−10 ms. All windows use the same 10,000 Hz sample clock. A positive change means the electrode voltage relative to its mid-back reference rose. It does not locate the generator of that change. [Recording study](https://doi.org/10.1371/journal.pbio.3002828)

The development set contains the first 80 eligible events from one median-nerve run in each of four people. Two supplied run 03 and two supplied run 02. The fixed choice was run 03 where present, otherwise the lowest numbered available median run. Each person supplied all 80 events to a single validation fold. Each fit used 240 events from the other three people. An earlier eight-event measurement overlaps one development participant. The browser forecasts with weights fitted to all 320 events. Its synthetic input has no later measurement against which to score it.

The input comprises ten five-sample averages from −15 to <−10 ms and six from 5 to <8 ms. Columns in the weight file are Biceps (armpit nerve recording), SC6 (neck), Thumb (muscle), CP4 (scalp) and ECG (heart). All voltages are microvolts with the original references. Each person’s event index, from 0 through 79, is divided by 79. Scaling uses only fitting rows, with a mean and population standard deviation for each channel in each time window. A scale below 0.00000001 µV is replaced by one. Both fitted Transformers mask pre-pulse armpit voltage to zero after scaling. The version without the arm channel masks the six early arm inputs as well. All 16 positions receive the event-order covariate.

A learned projection maps six values to 16 features at each position. The Transformer adds learned positional vectors and one layer of two-head self-attention (eight features per head), followed by a 16-to-32-to-16 feedforward network with GELU activation. Both operations use normalization before the block and a residual connection. A final layer normalization and average across the 16 positions feed a scalar linear readout. Multiply by the fitting target standard deviation and add the fitting target mean to recover microvolts. AdamW fitted 100 full-batch updates at a learning rate of 0.003, weight decay 0.01 and seed 1701. There was no dropout, checkpoint selection or early stopping.

The wrong-event comparison rotates each person’s early armpit traces by 37 of 80 events within that same person. Training and validation both use this mismatch. All other inputs and targets keep their own event index. The test breaks event pairing while preserving the armpit signal values. It does not establish a chance distribution or remove every event-order dependency. The linear comparison models use ridge regression with a penalty of 32 on the sum-of-squares objective and an unpenalized intercept. The simple subtraction model predicts the training group’s mean raw later SC6 voltage minus the event’s observed baseline.

Scores are calculated per person and then averaged with equal weight. The primary score is the mean absolute difference between predicted and measured neck voltage change. Gain is comparator error minus the full Transformer’s error. The development criterion requires positive mean gain against both the no-arm and wrong-event Transformers, and gain against both for at least three of four people. The sign test for the primary no-arm comparison is two-sided and drops exact ties. Four people afford little precision even when all differences agree. The earlier eight-event measurement used the shorter −15 to <−13 ms baseline. Biological propagation, movement, clinical performance and generalization to a new population require other evidence. ## Six new people

After fitting ended, another six people from the same study each supplied their first 80 qualifying events using the same run-selection rule, channels and times. Each person’s earlier and later data stayed together throughout the assessment. No assessment data entered fitting, scaling, the choice of inputs or the selection of a model. The comparison uses the same Transformer with the correct arm reading and with the early arm reading from 37 events ahead within that person, wrapping around at event 80. This holds every weight fixed while breaking the pairing. The independent-person criterion requires improvement on both the no-arm and wrong-pairing contrasts for at least five of six people, as well as lower mean absolute error on both. The secondary robust linear model averages one-millisecond bins and starts from the last available neck reading at 7 to <8 ms; its matched wrong-event control substitutes all eight armpit bins. Its criterion requires at least 5% lower average error against both controls and improvement in all six people. [Independent assessment scores](assessment.json)
