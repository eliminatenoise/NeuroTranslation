What does the word add?

The eleven observed poses give the model the stride already under way. The action label tells it which gait to continue. Keep the same movement and switch the label to see how far the forecast moves.

Each recording has one catalogue label. Switching a walk to “run” here gives a different prediction for the same history. The recording can only show the gait the person actually performed.

How close did it get?

Use your own measured coordinates

Choose “My pose window” under Observed movement. Paste or drop a JSON object with action (“walk” or “run”), timesS (11 timestamps, 0.05 seconds apart) and positionsMm (11 frames × 18 sites × XYZ). Use the original right-handed lab frame, millimetres and +Z up. The last observed frame defines time zero on the player. The model accepts an arbitrary starting clock.

Each left and right waist site averages that side’s front and back waist markers. The two waist sites must be at least 40 mm apart in the last frame’s horizontal plane.
