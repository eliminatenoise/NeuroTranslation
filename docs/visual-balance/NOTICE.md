# Recordings and source

Steven M. Peterson and Daniel P. Ferris collected and published the **Perturbed beam-walking task**. NeuroTranslation used the visual-rotation walking sessions in OpenNeuro ds003739 version 1.0.3. The authors release the data under CC0 1.0. [Versioned dataset](https://doi.org/10.18112/openneuro.ds003739.v1.0.3) · [Acquisition and processing](https://doi.org/10.1016/j.dib.2021.107635) · [Original balance study](https://doi.org/10.1523/ENEURO.0207-18.2018)

This package contains fitted model parameters, inference code, a synthetic example generator and aggregate scores. All example signal and marker traces shown by the interactive controls are invented. No individual participant recordings or event histories are distributed here.
