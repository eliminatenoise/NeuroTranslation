# Visual balance

Extract the entire ZIP into one folder. Open **index.html** in your browser. The Windows, macOS and Linux launchers open that same file in your default browser. If your operating system asks you to confirm a downloaded launcher, you can open index.html directly. All model calculations and recorded-walk result tables work offline. Links to related publications require internet access.

Choose the rotation seen through the headset. Adjust the amplitude or phase of an invented movement. The controls regenerate motion and voltage histories and pass them through the fitted Transformer. Choose the second model to withhold scalp input as during its training. Under **Other recordings & timing** you can mark the eye, neck or leg electrodes unavailable. This edits the example’s measured-input mask. It cannot separate biological sources within a scalp recording.

Read the three signed displacements for each marker in millimetres. The sacrum is the bony region at the base of the spine. The graph lets you inspect one source axis at a time. Positive and negative follow the archive’s axis conventions. The final diamonds are model outputs for 125 ms after the last stored input. An invented example has no observed future against which to score that output. The study results on the same page give errors measured in recorded walks. The archives were filtered and aligned offline, limiting any inference about live timing.

See [source and reuse](NOTICE.md) for the versioned dataset and acquisition paper, and SHA256SUMS for the file checksums.
