# Where will the wrists land?

Open **index.html** in a browser, or use the Windows, macOS or Linux launcher beside it. Extract the complete package before opening it. The reader works offline without a server, port, account, camera or Python installation. Each launcher opens the same local page in your default browser.

Choose a fictional left or right onset, a model, a comparison and a horizon. The earlier points and later reference are generated from equations. The public checkpoint was fitted on 60 fictional movements. The regularized linear model and the two-arm Transformer run in your browser. Changing a selection recomputes the forecasts.

A forecast and a later wrist position occupy the same camera plane. Their straight-line distance gives error in detector pixels. Dividing that distance by the median prior shoulder width expresses the error in shoulder widths. For an example with missing values, use **Available measurements** to see which predictions and comparisons survive.

For your own data, open [the input guide](input.html). The optional private fit uses the same portable JSON schema as the NeuroTranslate Python package. The recorded experiment used separate private fits. Its published results are aggregate measurements across events. [Read the study](../papers/cross-person-wrist/index.html).

Peterson and colleagues describe AJILE12 in *Scientific Data* (2022), DOI 10.1038/s41597-022-01280-y. Their dataset, *AJILE12: Long-term naturalistic human intracranial neural recordings and pose*, is DANDI 000055, version 0.220127.0436, DOI 10.48324/dandi.000055/0.220127.0436, CC BY 4.0. This reader includes no participant recordings or participant-trained coefficients.
