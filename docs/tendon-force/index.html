Tendon-force preview

Enter a short history of a muscle’s electrical signal. The page predicts the corresponding tendon force added up over the next 100 milliseconds.

Technical edition Simple edition

Muscle signal

Uses the signal from the lateral gastrocnemius (LG), one of the muscles that pull on the Achilles tendon.

Electrical signal before the forecast

Use the root-mean-square (RMS) reading in millivolts for each 20-millisecond interval. RMS summarizes the size of a changing signal. Enter the oldest value first. The last interval ends when the forecast begins.

The starting values are invented.

Next 100 milliseconds

The result is tendon impulse, which adds up force over time. For example, a steady force of 10 newtons for 100 milliseconds gives 1 newton-second (N·s).

How the estimates differ

Both ridge models multiply each input by a learned weight and add the results. The first uses the values in millivolts. The second divides the whole history by its overall signal size first. The simple method uses the same training-set median each time for the selected tendon.

These experimental predictors were fitted to published guinea fowl recordings. The results are model estimates from the ten values above.
