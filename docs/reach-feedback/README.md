# What follows a reach?

Extract the entire ZIP into one folder. On Windows double-click **Open on Windows.cmd**. On macOS open **Open on macOS.command**. On Linux run **Open on Linux.sh**. Opening **index.html** directly also works on all three. The reader runs in a browser with JavaScript enabled, including with the network disconnected.

Choose one of four fixed recorded reaches. The first chart shows the hand in two of the three measured dimensions. Both axes have the same distance scale. The second chart shows ten 10-ms bins for the selected electrode and sort. Hovering is optional. Use Tab to reach each control, the arrow keys to change the selected option or slider, and Enter or Space to open a disclosure. “Read the numerical forecasts” gives all three hand coordinates and all 23 unit totals. The first training reach is from a warm-up block. Its movement prediction is in-sample. The sequence has recorded later spikes and no cross-fitted count prediction.

“Change the earlier measurements” lets you shift the five most recent hand X samples by one fifth through five fifths of the chosen final shift and add whole spikes to one unit in the most recent bin. Every nonzero edit recalculates the fitted models and hides the original future path and spike counts. “Restore recording” returns to the original measurements.

The reader uses the primary seed-17 movement Transformer and two seed-17 count Transformers. Forecast paths are measured from the last known pose. Raw arrays in examples.js use metres for the hand and elbow markers and centimetres for the independently framed handle. Counts remain spikes per recording bin. The embedded files contain the 20 earlier poses, spike counts and elapsed-cue fields plus ten measured future displacements and ten later spike-count bins for each fixed example. The results file reports the group comparisons for three seeds, learned separately. See the data notice for time alignment, provenance and rights.
