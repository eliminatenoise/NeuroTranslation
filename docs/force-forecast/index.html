How the methods differ

A correction starts with the hold-steady estimate and adds an amount learned from the earlier readings. A direct forecast estimates the result from those readings. A recurrent method carries information from one reading to the next. The mixed-activity versions learned from a second collection of force recordings as well as the walking data.
