NeuroTranslation

Forecast an unfamiliar body

Watch a set of points move. The model sees their positions and times. It estimates where each visible point will go, without being told the species or the names of its body parts.

This is an invented motion. The fitted model learned from optical recordings of rodents, flies and worms.
