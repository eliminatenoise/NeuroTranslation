NeuroSurge

Move a virtual body and see a second body mirror your movements.

GitHub repository

Move from the motor strip

Aim at the motor strip, a part of the brain that helps control movement. Watch which part of the virtual body moves. The electrical activity and movements are simulated.

Both editions play the same. Lite downloads smaller anatomy files. Use a desktop browser with a keyboard and mouse or trackpad.

Download Lite offline

Extract the ZIP and open the launcher for your computer in lite. Node.js 18 or later serves the game to your browser from this device. Press C to use a local video or timed pictures. Save the movement as a take, then press F and enter “replay my take”.

Desktop launchers

Get shortcuts to the online game for Windows, macOS or Linux, or follow the steps to run a local copy of the source.

NeuroTranslation

Test how much brain, muscle and motion recordings tell us about the movement that comes next.

GitHub repository

Try NeuroTranslate 0.0 in your browser

Choose a measurement, such as a wrist angle or the load under a foot. Start with a built-in example and compare the forecast with a later reading where one is available.

Compare walking forecasts

See how a forecast based on movement and forces compares with forecasts that also use a trained model. The demo shows the Compact and Research Edition blends separately.

Browse movement experiments

Run more examples in the browser, including forecasts for a wrist and for walking. Separate studies show where recordings help and where they add little.

Run NeuroTranslate 0.0 locally

Download and extract the demo. With Python 3.10 or newer and NumPy installed, open the demo launcher for your system. Choose a movement task or change an input to see how the forecast changes.

Model downloads

Get the saved model files and follow the instructions to run them. A saved set of learned model values is called a checkpoint.

NeuroTranslate 0.1 Research Edition setup

Run a force forecast from an example of muscle activity and force underfoot. To run the forecast, use Linux on an Intel or AMD computer and download the original model separately.

Interoceptomics

Explore how the nervous system carries signals about movement and the state of the body.

GitHub repository

Open the 3D atlas

Turn the brain model and follow illustrated routes between the brain, spinal cord and body. The atlas shows anatomy and describes proposed links between structures.

Explore the experiment guide

Choose human movement or animal learning. The guide labels the recorded examples and shows the steps of the proposed work.

See heart and breathing recordings

Move through recordings that show electrical activity from the heart, chest vibration and breathing measured together.

Download the atlas for offline use

Extract the ZIP and use the launcher for Windows, macOS or Linux with Python 3.10 or newer. The bundle includes the illustrated guide.

Read Backslash of the Brain (PDF)

See the anatomy plates and read where each illustrated route starts, passes through and ends.
