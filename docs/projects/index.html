NeuroTranslation

Test how much brain, muscle and motion recordings tell us about the movement that comes next.

GitHub repository

Try NeuroTranslate 0.0 in your browser

Choose a measurement, such as a wrist angle or the load under a foot. Start with a built-in example and compare the forecast with a later reading where one is available.

Compare walking forecasts

See how a forecast based on movement and forces compares with forecasts that also use a trained model. The demo shows the Compact and Research Edition blends separately.

Browse movement experiments

Run more examples in the browser, including forecasts for a wrist and for walking. Separate studies show where recordings help and where they add little.

Run NeuroTranslate 0.0 locally

Download and extract the demo. With Python 3.10 or newer and NumPy installed, open the demo launcher for your system. Choose a movement task or change an input to see how the forecast changes.
