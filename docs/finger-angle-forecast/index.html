Readings for your own forecast

Use ten rows in history, starting with the oldest. The recordings had one reading every 40 milliseconds. Give four angles in degrees in the order index, middle, ring and pinky. To include ultrasound, give four angles followed by sixteen values from the ultrasound image in each row.

Prepare the ultrasound values

Use the same measurement setup as the study. Restore the archive’s amplitude scale and divide each image into four rows and four columns of equal tiles. For each tile, average its pixel amplitudes and take the natural logarithm of one plus that average. List the tiles left to right, starting at the top. The browser subtracts the first value for each tile when it runs the ultrasound-change method.

Files stay on your device. The page uses stored readings and keeps the camera off. The archive provides paired frames for the study and leaves live sensor delivery time unmeasured.
