Can six forecasts share a model?

One set of recordings follows people balancing. Another follows a macaque reaching. A third follows a macaque grasping and pulling a sliding object. Each supplies two things to predict. We asked whether fitting their six forecasts with one shared set of Transformer layers helps.

Sharing helped on reaching

The compact shared model reduced arm and handle movement error by 0.034 fitted standard deviations against the compact model trained on that task alone. The wider shared model lowered the spike-count penalty by 0.201 nats against its own separate model. The compact shared model had the smaller count penalty overall.

Both shared models had higher average errors on the two human balance forecasts and both grasp forecasts than their own same-width controls. Lower values are better. Compare the two scores within a row.

What each comparison used

Each task has its own input layer and readout. The common layers read the past sequence and supply the information for the next forecast. At each width, the shared fit and its separate controls started from the same weights. Each fit used 480 updates. We tested one training seed.

The human comparison used 761 windows from three people. The reaching comparison used 199 windows from 78 original trials, and the grasp comparison used 733 windows from ten trials. Windows from the same person or original trial count together. These groups came from previously used archives. The external recordings remain reserved.

What held up in the second fit?

The two fits agreed on which model had the smaller error in 11 of 12 comparisons. Averaged across the two fits, the compact shared model reduced reaching movement error by 0.023 fitted standard deviations. The wider shared model reduced reaching spike-count loss by 0.174 nats. Each comparison uses a separately trained control of the same size.

Both grasp forecasts still scored better in their own models at both widths. The wider human pelvis forecast changed direction. Its paired range across people included zero. Both fits used the same previously studied groups.
