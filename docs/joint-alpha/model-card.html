NeuroTranslate 0.0 joint alpha

What is inside the checkpoint?

Every task updates the same 8,576 parameters. Changing a task changes the input layer and readout that fit its instruments and units. The shared weights still carry what the other tasks taught them.

Size and architecture

21,445 trainable parameters, all float32. Width 32, 4 attention heads, depth 1, and 64 hidden units per feed-forward layer. The encoder reads the observed history and a missingness mask with a fixed time encoding. A learned empty-memory position participates in attention.

The compressed checkpoint occupies 104,761 bytes, including schema, metadata and training-set normalizers. Trainable parameters alone occupy 85,780 bytes. SHA-256 f58dec8857015d84962aeb00259badf71b42d9bf7105cec35851a87826ed57d6.

Inputs, outputs and data

The shapes below describe one history. C is the number of local recorded-unit candidates in that input. Human EMG and sacrum rows come from the same events, and the two macaque targets come from the same reaches. Adding these row or group counts across tasks would count those source windows twice. Groups mean people, trials, videos or recordings according to the task.

The five input collections supply 109,644 distinct source windows when the two pairs of targets sharing a history are counted once. Each of 1,920 optimizer updates takes 32 draws per task, or 61,440 per task over the fit. Sampling with replacement can revisit a window.

Worm and zebrafish · optical fluorescence

Four optical readings follow a region of interest in a worm or a zebrafish recording, alongside their time offsets and an assay indicator. Each source uses its own development recordings to set the scale. History approximately 3.6 s · Forecast approximately 1.2 s ahead.

Input order. optical fluorescence (assay-specific development SD), relative sample time (s), fish assay (0 or 1)

Output order. next fluorescence (assay-specific development SD)

Worm source fluorescence and fish ΔF/F are distinct source quantities. Each assay uses only development observations to set one mean and SD, including every held forecast. Upstream bleaching correction, interpolation and segmentation can use recording-wide data. Optical activity is not spikes or muscle motion.

Rat · next recorded unit to spike

Each candidate has an earlier event count, three counts that give recent spikes more weight, and an indicator of activity in the last occupied bin. Candidate numbers apply within this input. Next occupied 1 ms bin containing a single spike · Elapsed time varies.

Input order. log1p trial count (log(1+count)), log1p trace 10ms (log(1+count)), log1p trace 100ms (log(1+count)), log1p trace 1000ms (log(1+count)), current bin fired (0 or 1)

Output order. One probability per eligible candidate, normalized over the local roster.

Offline sorter, unverified continuous detection; sorted-unit identity is recording-local.

Which tested size earned its place?

The development comparison held out whole source groups. Each candidate saw the same task mixtures and update count. The score divides each task’s error by its development reference, averages the paired outcomes within each domain, then gives five domains equal weight. Lower is better. The selected candidate scored 0.68372. The first width comparison used one seed. The refinement compared two seeds on the same inner split, then the selected configuration was refitted on all development data. Wider candidates included 256 and 512 channels.

What happened on the held recordings?

Each score gives equal weight to groups within its split. Lower values are better. The matched single-task model used the same architecture and update count. The source reference uses each study’s comparison rule. For macaque counts, a second comparison halves the recent count and adds half the training-set mean. The trained specialist, where available, is a separate historical fit. The last column repeats a training mean or assigns every candidate equal probability. A dash means the comparison was unavailable. Group counts can include several trials from one animal. These recordings had already been studied.

The joint fit had lower primary error than its matched single-task fit on 5 of 11 held comparisons. The two human outcomes favored single-task fits. The cortical count and fluorescence tasks improved over single-task training, yet a smoothed rate and repeating the last fluorescence reading respectively gave lower errors.
