NeuroTranslate 0.0 joint alpha

A reach leaves two records. A camera catches the movement, and electrodes count the spikes. Give NeuroTranslate the recent history of both and ask where the hand moves next. Switch the question and the same trained weights estimate the spike counts instead.

Run your first forecast

  1. Extract the whole ZIP. The neurotranslate-0.0 folder contains the model, examples and three Demo launchers.
  2. Use Python 3.10 or later with NumPy installed in the Python environment you will run. For a fresh environment, run python -m pip install numpy first. The first install usually needs a network connection. On Windows you can use py -3 in place of python. On macOS or Linux use python3.
  3. Open Demo on Windows.cmd, Demo on macOS.command or Demo on Linux.sh. If your system opens a launcher as text, open a terminal in the extracted folder and run python joint_demo.py. The launcher prints the local address and opens it in your browser. Keep the terminal open while you use the demo.
  4. The demo opens on a fictional human lower-leg muscle forecast. For the reaching example above, choose macaque hand, elbow and handle movement. Change an earlier reading and run the forecast, or describe an outcome to choose another task. The local phrase matcher asks before replacing your input with a different task’s example. An optional local sentence encoder can supply a JSON task proposal. Its separate language weights are optional. The samples are invented. Open the checkpoint fingerprint underneath the forecast, switch tasks, and compare the fingerprints. To close the server, press Ctrl+C in its terminal.

Once NumPy is installed, forecasts run offline on the CPU. You can save a changed input from the browser and replay it from the same folder.

python predict.py
python predict.py --list-joint
python predict.py your-input.json

What did the shared weights learn?

All 7 tasks update one temporal-attention encoder during training. Each uses its own input layer and readout. The paired human and macaque tasks see earlier values of the quantities they predict, alongside other sensors. Unrelated experiments supply separate training examples.

See every task, the measured errors, model sizes and runtime. The common encoder contains 8,576 of the 21,445 trainable parameters.

The joint fit had lower primary error than its matched single-task fit on 5 of 11 held comparisons. The two human outcomes favored single-task fits. The cortical count and fluorescence tasks improved over single-task training, yet a smoothed rate and repeating the last fluorescence reading respectively gave lower errors.

Where do the simpler models win?

The earlier movement model, trained task adapters, and specialist forecasts still run with the input files from their studies. Their results refer to those fits. The comparisons below also test how much a model can learn from combining different signals or adding recordings.

When the human balance study added both people and examples, many model rankings reversed. Keeping the example count fixed gave a different answer. In the spike study, the smallest fit picked the eventual winner in each held recording, but the rat and turtle favored different models. Read both training-size studies.
