Twenty milliseconds of a grasp

Picture a handle that slides as you pull it. One sensor follows the handle's travel. Five others respond to contact and load. In one macaque recording, electrodes also picked up short electrical pulses called spikes. Could those pulses tell the model what the sensors would read 20 milliseconds later?

The moving object's sensor

Adding spikes grouped across units reduced the error by 3.68 counts in the first comparison against sensors, time and task cues. It increased error by 0.16 counts in the second. A model without spikes had the lowest error in both fits. Swapping in an earlier trial’s spikes made both grouped-spike forecasts worse.

How the comparison worked

The input stops before the forecast. We gave each model the preceding 100 milliseconds and used the same time window for every comparison. The attention models share the existing NeuroTranslate Transformer weights. New input and output layers learn how to read this recording. One fit sees the sensor history. A second sees the same sensors, the time since the go signal and the two task cues that told the animal how to grip and how much resistance to expect.

In two more fits, we added spike counts. One version keeps the identified units separate. The other looks at the spike counts as a group. We then replaced those counts with the record from an earlier trial with the same cues and timing. That leaves the sensors and cues as they were.

The comparison scored 2,937 windows across 40 original trials. Each original trial carries the same weight. Both fits were checked on the same later trials in the same recording. The authors identified spike units offline, which leaves live decoding untested. A second animal was reserved from this experiment.
