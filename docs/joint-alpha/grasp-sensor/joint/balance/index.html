Can one model learn both forecasts?

Balancing two forecasts

A grasp gives us two things to predict. One is how a sensor reading changes as an object slides. The other is how many short electrical pulses nearby brain cells produce in the next 20 milliseconds. What happens when both tasks have the same influence on the layers they share?

Spike forecasts improved. Movement forecasts got worse.

Against training both forecasts with fixed equal weights, balancing the updates reduced the spike-count penalty by about 0.0034 and 0.0047 in the two fits. The model trained only on spike counts was still close enough that the paired uncertainty ranges included zero.

Check that balancing changed the training

The model uses the same fixed Transformer as the previous experiment. With equal weights, the task that predicts physical readings usually sends a larger update to the shared layers. In these fits the typical ratio was about three to one. We measured the size of each update before combining them. Balancing made their sizes equal at every step where both sent a measurable update, 599 steps per fit.

We scored 1,100 windows from 15 original trials in one macaque recording. The split comes from trials previously used for fitting. The two fits use the same evaluation trials, and the result for each trial has equal weight. Spikes were sorted after recording. A different animal and a live recording remain untested.
