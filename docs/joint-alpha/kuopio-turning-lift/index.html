Where does the wrist go in a turning lift?

Lift a box straight up. Then lift it while turning. Your right wrist has a different path to follow. We tested whether seeing some of each lift during training helped a model forecast that wrist’s next move.

Two changes, two higher errors

Using both lifts raised the error of the wrist-only linear model. Adding current muscle readings raised the turning-lift attention model’s error when it already had wrist and floor-force readings. In each comparison, error rose for all six people.

We chose both comparisons before opening the turning recordings used to check the forecasts. A sign test counts how many people’s errors rose or fell. For each comparison, the exact two-sided test gave p = 0.03125, with no adjustment for the two tests. Each person carried the same weight. The error changes use the unrounded scores.

The same number of examples

Cameras tracked two marks on each wrist as people lifted a 12 kg box. Plates underfoot measured external forces. Electrodes recorded small changes in voltage from six shoulder and upper-back channels. From 25 readings of both wrists over 240 ms, each model forecast where the right wrist would be 100 ms later. The current force and muscle histories use complete recording blocks two camera frames earlier than their matching wrist positions.

All three training groups used 1,986 examples from the same seven people. One group used straight lifts, one used turning lifts and the third took half from each. Each person contributed the same number of examples to each group. That lets the comparison ask what changes when the mix changes, with the total number held fixed.

The six people used to check the forecasts had also supplied the earlier straight-lift test. These are new recordings of a different movement, from the same held-out people. We fixed the fits and saved the predictions before reading later wrist positions. Of 3,278 planned windows, 469 lacked a usable input history and one lacked a later wrist position. Every forecast was scored on the same 2,808 windows.

A linear model adds up weighted readings. An attention model can weigh different moments in the history differently for each prediction. The smallest error across all combinations was 12.13 mm, from the attention model trained on both lifts with wrist positions alone. That was a separate comparison from the planned wrist-only linear test.

Run a forecast on your computer

Download the fitted models and example. Extract the ZIP. With Python and NumPy installed, run python forecast.py from that folder. It prints how far the right wrist is predicted to move in each direction over 100 ms.

The included example uses generated readings. To see all 38 forecasts, run python forecast.py --arm all. To check them against the bundled reference, run python forecast.py --self-check. The guide inside the ZIP shows how to supply a history of your own.

Forecasts run offline once the dependencies are installed. The package ran on Linux in an isolated network. Windows and macOS launchers are included and await testing on those systems.

What each sensor measured

The wrist marks measure movement. The plates measure external force underfoot. The muscle channels measure electrical activity. The setup gives no direct measure of grip force or of the force produced by an individual muscle. It also cannot tell us why a particular wrist path occurred.

The muscle channels stayed in the archive’s recorded scale because the voltage units disagree across the source labels and device description. The plate readings retain their local directions and stated units. The comparison had no independent known-load calibration. The results cover these recorded turning lifts on this instrument clock.

Using muscle readings from one second earlier gave a mean error of 18.96 mm for the turning-lift attention model. Moving both the muscle and floor readings back a second gave 18.79 mm. Those shifts can also change which phase of the lift a recording shows.
