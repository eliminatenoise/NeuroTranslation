Pelvis marker studies

Predict the next part of a stride

When you run, your hips rise and fall in a repeating pattern. The stride forecast looks for an earlier part of the run that resembles the latest camera readings. It estimates the next 100 milliseconds from what already happened at that point in the earlier stride. A small attention model then adjusts that estimate.

The learned adjustment reduced average four-marker error from 8.04 to 5.79 mm on recordings from 40 runners at the University of Bath. The model learned its adjustment from a separate Brazilian running dataset.

Compare the forecasts

Each forecast estimates how far the average height of the named markers will rise or fall. Each person counts equally. Smaller errors are better.

Where the result applies

The test used the first ten seconds of each fixed-speed treadmill trial. The Bath sample supplied no histories with original camera gaps. In development, only four of the six Brazilian validation runners contributed scoreable histories with those gaps. A wider test needs more running conditions and more people with original gaps.

How the test was run

The running condition was 12 km/h at a 1% incline. The archive lists 46 exact recordings for that condition. One was reserved to verify the file format and five lacked landmarks needed for an endpoint or to check which way was up. The other 40 supplied the comparison.

The camera stored 250 readings per second. Both stride methods used 800 milliseconds of earlier readings. Each target was scored only when its markers had positive reconstruction quality at issue and outcome. The same issues and outcomes were used for all methods. The attention adjustment had 7,618 fitted parameters, frozen before the Bath recordings were scored.
