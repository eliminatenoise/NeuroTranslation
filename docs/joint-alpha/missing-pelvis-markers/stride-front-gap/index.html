Stride forecast study

Forecast with a front marker missing

When a camera loses a marker, an earlier part of the run may still help. We tested a model that reuses movement from a similar part of the previous stride and adds a learned correction.

In 11 held-out runners, the correction reduced average error from 8.62 to 6.29 mm for all four pelvis markers. The rear-pair error fell from 9.11 to 6.66 mm. The correction helped ten people on the first target and all eleven on the second.

What the gaps allow us to test

The camera lost at least one front marker during the previous 800 milliseconds. Both rear markers remained available over that history. To score either target, its markers had to be available in both the last input reading and the reading 100 milliseconds later. This left some windows with a usable rear target and no four-marker target.

These runners appear in a later release from the lab that supplied the training data. Their records were excluded from fitting. Rear-marker gaps and the two other running speeds had too few participants for the same comparison.

How the test was run

We used the authors’ unfilled camera coordinates at 150 frames per second. The source flags show which readings are missing. The available readings lack per-point reconstruction quality and camera counts. Each model used the same outcome reference for each scored window. All forecasts were fixed before numerical outcomes were read.
