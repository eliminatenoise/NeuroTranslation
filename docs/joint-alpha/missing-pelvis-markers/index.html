What happens when the camera loses a pelvis marker?

Turn away from a camera and a marker may disappear behind your body. The model still has to predict the same movement. We hid readings from archived recordings and kept the recorded outcome fixed so we could compare errors with the same people and trials.

With only the two back readings supplied, training with missing inputs reduced the attention model’s four-marker error from 31.62 to 13.03 mm. A linear fit for those same inputs averaged 6.29 mm. The comparison used 431 chair forecasts from 9 people.

For the separate target at the back of the pelvis, error fell from 30.57 to 10.16 mm with the same change in attention training. The linear fit averaged 4.38 mm on that target.

How the study kept the targets separate

The model computes its height reference using only the markers present at prediction time. Missing positions and any missing recent changes remain marked as unavailable. For scoring, the four-marker target still uses all four originally recorded heights. The back-marker target uses the two recorded back heights. The model saw the same two definitions while training.

We fit on Gait120 and Monash sit-to-walk, then tested on different participants recorded at Notre Dame. The comparison used processed tracks and simulated missing inputs. It measures performance when earlier readings are withheld while the later target remains available.

The squat table includes 4,457 matched forecasts across the recorded trial periods. A later descriptive check looked only at the 579 times when the back markers had already moved at least 5 mm in 150 ms. With only the back markers supplied, the four-marker forecast error in that subset was 7.58 mm for attention trained with missing inputs and 4.21 mm for the linear fit.
