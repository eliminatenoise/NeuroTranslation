Pelvis marker study · Deep-squat recording gaps

Can a model learn when to correct speed?

A recent change in height gives you a starting point for predicting pelvis movement. We trained one model to correct that estimate and another to predict the full change directly. Then we took both to a treadmill archive from a different lab.

Direct prediction did better on walking

We tested both models on sixteen people, eight from each of the archive’s younger and older groups, and deliberately hid some earlier readings. The correction reduced both errors by about 1.11 mm compared with the speed forecast. The direct attention model had lower average error than the correction on both targets.

Both targets cover the next 100 milliseconds. One averages the height of four markers on the pelvis. The other averages its two back markers. The treadmill comparison gives equal weight to each of the two participant groups and each of the five reading conditions.

A marker must appear twice to show movement

When the latest pair of frames shared a marker, the speed forecast could use its change in height. When those frames shared none, it looked farther back for two readings from the same marker. When no marker appeared twice anywhere in the history, the reference forecast zero movement. Both learned forecasts had larger errors in that last situation.

What each model saw

Each forecast used five frames spaced 50 milliseconds apart. The two attention models received the same readings, the same speed estimate and the same information about which frames supported it. The earlier lab split gave the correction the lower error. The scores below come from the people used to choose the candidate, with gaps added to the recordings.

The two attention models had the same 9,698 parameters per fitted copy. We averaged three copies trained with different initial values for each method.

The treadmill comparison used 4,994 source windows and five kinds of input, from complete readings to one-time sightings. The gaps were inserted in the earlier inputs only. The archive preserves coordinates at 100 frames per second and carries no positive residual or camera-contribution evidence for these pelvis tracks. Its processing history limits what this trial can establish about original camera dropouts. Live webcam tests remain open.
