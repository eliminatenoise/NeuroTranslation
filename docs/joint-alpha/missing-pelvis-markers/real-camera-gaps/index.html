When camera markers disappear

Four small markers tell an optical camera system how the pelvis moves. During a deep squat, some go missing. We forecast how far the pelvis will rise or fall in the next 100 milliseconds using only the readings available at the time.

The simple forecasts had lower error

Teaching the attention model with hidden readings reduced its error on real gaps. Continuing the recent speed gave the lowest average error for both targets across all the scored gaps. A linear fit also had lower error than either attention model.

The four-marker centre averages the height of two marks at the front of the pelvis and two at the back. The back-marker centre uses only the two at the back. A score requires the target’s own markers at forecast time and 100 milliseconds later.

A missed reading can also hide the answer

There were 777 scheduled windows with a gap in the five earlier camera frames. In 57, fewer than two markers remained at forecast time, so the models abstained. In 590 of the remaining 720, at least one of the four marks was missing at forecast time. Five more lost a required mark at the later frame. The two back marks gave an answer in 719 windows. Each scored target had data from 11 of the 12 test participants.

When the back markers were already moving

This comparison keeps windows where the average height of the two back marks changed by at least 5 mm over the preceding 150 milliseconds. In that subset, the linear fit had the lowest back-marker error. The speed forecast still led for the four-marker centre.

When a gap matched an earlier test pattern exactly

The older study built a separate linear fit for each of five predetermined ways markers could go missing. Of the new windows with a measurable back-marker outcome, 380 had one of those exact earlier patterns. The linear fit for the exact pattern had the lowest error on those windows. There were no such windows with a measurable four-marker outcome.

How the comparison works

We used the original, unfilled optical trajectories from the Kuopio Full-Body Dataset. The camera system recorded 100 frames per second. Each forecast used five frames, 50 milliseconds apart, ending at forecast time. We kept the original missing readings and used the C3D quality fields to omit finite values whose measurement residual was zero. The files supply a residual for each reconstructed point. They carry no per-camera contribution flags.

All forecasts used the same available heights in millimetres. Both attention versions kept their original weights. The new linear fit was trained and selected using the earlier datasets before opening the 12 deep-squat recordings. The speed reference projects each measured marker’s most recent 50 milliseconds of movement forward. This comparison used camera heights alone, without a minimum force cutoff.

We saved the forecasts before calculating the later heights. Each reported error is the average of the participants’ mean absolute errors. A separate reader and version of the attention code reproduced the main results. The recordings came from the same people as a different wrist study. Their deep-squat trials and all Kuopio data were outside pelvis model fitting.

These results concern recorded reflective markers during deep squats. Live webcam performance remains unmeasured.
