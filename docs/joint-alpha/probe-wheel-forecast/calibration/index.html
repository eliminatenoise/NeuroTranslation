Back to the wheel forecast

Can a wheel forecast learn from its last guess?

A mouse hears a beep and can turn a wheel. Fifty milliseconds later, we predict whether the wheel will turn at least 0.006 radians, about a third of a degree, in the next 100 milliseconds. As trials finish, can their results help the model give better chances for the next turn?

Completed trials helped the model judge the next turn on quiet wheel histories. The lowest average error came from updating the linear model that used the wheel and cue.

A result has to arrive before it can help

Imagine making a second forecast while the first is still waiting for its wheel reading. That reading belongs to the future. In this replay of archived recordings, a forecast could learn from an earlier trial only if that trial’s full 100-millisecond window had ended strictly before the new forecast. If the times were equal, the reading had to wait.

We called a history quiet when all the wheel’s recorded angles in the preceding 200 milliseconds matched the starting angle. With no new reading, we carried forward the last angle. This describes the wheel at its sensor’s resolution. The mouse’s paws and body can still move.

Earlier results improved the wheel-and-cue forecast

We tested six new mice across three labs that supplied no earlier forecast recordings. The main comparison used 396 quiet trials with a matching earlier spike record. The wheel crossed the mark in 104 of them.

We measured the squared error between the predicted chance and the observed outcome, where a crossing is 1 and no crossing is 0. The average is called the Brier score. We scored each mouse first and gave the six mice equal weight. A smaller score is better.

For the linear model using wheel and cue alone, that score fell from 0.200984 to 0.125558. The updated score was lower for all 6 mice. The simpler forecast based on the recent crossing rate scored 0.136152.

Keep the model. Update the chance.

We kept the fitted models from the wheel onset study. The linear model weights inputs directly. The attention model can give different time blocks different weight. Both read recent wheel movement and the screen pattern, with optional bursts of brain activity called spikes.

One version used spikes from the trial being forecast. Another borrowed the whole spike history from the most recent eligible trial in the same session. It had to come earlier in the source rows and on the forecast clock, with the same screen-pattern side and visibility, quiet status and similar time since the last wheel reading. The wheel and screen inputs always came from the trial being predicted.

For each forecast, we used up to the latest 32 original predictions paired with completed outcomes from that same version of the model and kind of wheel history. One fitted number moved the model’s chances up or down on the log-odds scale, which keeps each chance between 0% and 100%. With no completed outcome, we used the original chance. All updates started afresh for each recording.

A simpler forecast used the recent fraction of completed trials with a crossing, without the model’s prediction. It started with the training frequency weighted as 20 trials and used up to the latest 32 completed outcomes of the same quiet status. The spike inputs ended 20 milliseconds before the forecast on the archived clocks. Live delivery time and the effect of brain activity on movement would need separate measurements.
