Can a wearable reading be matched to a foot load?

A grid of electrodes on the right lower leg measures small voltage changes from active muscles. A separate platform in the walkway measures the force of a foot pressing down. To test a forecast, we need to know which wearable readings came before that load on the same walk.

We could read both kinds of record from one person. The released files we checked leave the timing between them and the order of the walks unresolved. This source check stopped before fitting or testing a forecast.

Two measurements need a shared clock

Dimitrov, Bull and Farina describe a wired signal that linked the wearable unit and the motion-capture system during recording. We looked for the information needed to recover that link from their open files for slow, preferred-speed and fast walking on level ground.

The wearable table has broad activity labels. Its nominal rate is 2,000 samples a second. The table has no column for an explicit timestamp, trial ID or timing trigger.

Each force file came with a companion that identifies the file intended for analysis. Seven companions named the exact force file. Two pointed to a different file, so we set those force traces aside.

We counted a new load when the force on a plate rose to at least 20 newtons and stayed at or above that level for at least 20 milliseconds. First it had to be at or below 10 newtons for at least 20 milliseconds. We used the force clock alone for these counts. Identifying which foot loaded the plate requires separate evidence.

9 of 18 saved segments of a step cycle matched wearable samples exactly. Those matches located pieces of a step in the wearable table. The match to a whole force recording and the order in which the walks were recorded remain unresolved.

Why feedback waits for the whole walk

The authors smoothed the force traces using readings from both before and after each point. A later force reading can therefore change the smoothed value reported earlier in that walk. In a replay, the result of one walk can update a later forecast only after the whole walk has ended.

That rule keeps readings from later in a walk out of earlier forecasts. It still takes an independently verified time match and a record of when each walk was taken to test whether earlier walks help forecast a later one.
