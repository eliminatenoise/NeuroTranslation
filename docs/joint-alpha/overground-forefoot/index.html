How far does the forefoot move in 100 milliseconds?

Use 200 milliseconds of earlier recordings to predict the change in height at the front of the right foot. The cameras supply the earlier and later marker positions. The floor plates measure the vertical load. Electrodes on the legs measure muscle voltage. The four confirmation participants were kept outside model selection.

Familiar speeds · 1.5 to 3.5 km/h

5.96 mm for the strongest validation-selected model and 11.23 mm for Inkling. Both used the same 2,186 forecasts from 3 people whose motion, force and muscle recordings were available.

The attention model trained with movement alone averaged 5.44 mm on those forecasts.

Inkling's error minus the selected model's error for each person was +5.06 mm, +7.97 mm, +2.79 mm. Positive values mean larger errors for Inkling.

What went into the comparison?

The small attention model learned from the walking recordings. Inkling 2 Mini converted the same set of earlier measurements into numeric features using fixed weights. A fitted linear model used those features to estimate the later height change. The model choices were fixed using validation participants, and the confirmation forecasts were saved before the later marker positions were checked.

The recordings come from steady overground walking at prescribed speeds. Each person has equal weight, with equal weight for the speeds and trials they contribute. The force plates were zeroed during a checked unloaded interval at the start of each trial. Target marker coordinates were compared across the two export formats. Missing outcomes remain visible in the counts above.

These are archived recordings. The source includes gap filling, and the study addresses this task, this set of sensors and this population. It leaves live data arrival and other movement tasks untested.
