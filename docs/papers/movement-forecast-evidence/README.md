# What helped predict the next 100 milliseconds?

This NeuroTranslation supplement brings together three fixed tests of movement forecasts. Open [the standalone HTML](index.html) in a browser or read [the PDF](movement-forecast-evidence.pdf). Each edition works offline after download. Source links open the recordings and the reported comparisons when you go online.

## Rebuild the PDF

Keep `build.py` and `index.html` in the same folder. With Python 3 and Chromium installed, run `python3 build.py`. With Chrome, supply its executable path using `--browser`. The HTML sets the print layout and uses Liberation Sans when installed, with sans-serif fallbacks. The PDF includes selectable text and source links.

The supplement contains aggregate comparisons. The linked repositories and archive releases describe the fitted models, datasets and their terms. The original text and build code follow the NeuroTranslation repository’s CC0 dedication.
