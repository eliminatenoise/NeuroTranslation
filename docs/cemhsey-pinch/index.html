python fit_local.py --trial-list trials.txt --timing-mode nominal_release_index --output "my-fit.json"

How to convert one original trial

Extract the offline reader ZIP. Open a terminal in its python folder. With Python and the listed dependencies installed, run these commands with your own file paths. 

python -m pip install -r requirements.txt
python trial_io.py --input "trial.mat" --output "private-trial.json" --timing-mode nominal_release_index

Choose the new JSON file above. It contains sampled force readings and four forearm summaries, and stays on your computer. Without --timing-mode nominal_release_index, the converter makes a force-only packet. Use a new file name for each output.

For a terminal forecast from the packet, use python score_packet.py private-trial.json --issue 1660. Replace --issue 1660 with --score to see MAE and RMSE across all 592 cutoffs.

What the clock means

The force sensor sampled at 200 Hz. Twenty-four force ticks span a nominal 120 ms. Surface EMG used a separate 2,048 Hz sampling grid. The comparison uses the recorded sample indices. The offset between devices and the live availability of each signal remain unverified.
