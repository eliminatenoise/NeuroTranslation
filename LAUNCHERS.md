# Open NeuroTranslation

[Open the current preview](https://eliminatenoise.github.io/NeuroTranslation/index.html) or [download a launcher for Windows, macOS or Linux](https://eliminatenoise.github.io/NeuroTranslation/START.html). The launcher opens that same current URL, so later preview updates do not require a new shortcut.

Open the data companion to load the invented example or inspect compatible JSON and CSV recordings. File processing stays in your browser.

This is a data inspector and alignment tool. No trained NeuroTranslate model or model backend is connected. R11 manuscripts and the portable interface are source-only previews; no weights or runnable model download are included.

Windows uses `NeuroTranslation-Windows.url` and macOS uses `NeuroTranslation-macOS.webloc`. Download and double-click the saved bookmark; neither needs a terminal. Linux uses `NeuroTranslation-Linux.desktop` with the desktop's normal launcher handling. The ZIP also contains `Install-NeuroTranslation-Linux.sh` for a per-user application-menu entry. Extract it, then run `sh Install-NeuroTranslation-Linux.sh` in that directory. The installer opens no browser, uses Omarchy when available or xdg-open otherwise, and preserves a different file already using its managed name.

Keep file extensions and follow normal OS opening/trust prompts. These online launchers require a browser and network connection. They install no Node/Python package, paid service, model or background task. Native Windows/macOS execution and complete cross-platform behaviour remain untested; the package's checks cover file formats and isolated Linux installation only.

The start page links the available files, source ZIP, licences and current limitations. It does not turn source-only manuscripts or an absent model payload into a runnable model.
