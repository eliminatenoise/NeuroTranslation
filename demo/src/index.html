ONE CLOCK. DISTINCT OBSERVATIONS.

A shared timeline has to be earned.

Two files can describe the same movement without describing the same event. Alignment requires a declared shared subject, recording and clock. Unpaired datasets stay separate.

Each trace keeps its units and origin. Interpolation fills only the permitted gaps between samples. It does not turn a simulation into a measurement, or muscle electrical activity into a nerve recording.

Bring your own data

JSON / CSV

Files are processed in this browser. The application does not upload recording contents to a server.

JSON
One dataset with named streams, timestamps in seconds, units and provenance.
CSV
time,value columns; time is in seconds. Declare the organism, recording, signal type, units and origin at import.
Limits
5 MiB per file and combined packets. Up to 64 selected streams, 50,000 input samples, 5,000 aligned time points and 500,000 aligned values.

Use only data you have permission to process. Import checks validate structure; they do not verify your source or licence.
