# NeuroTranslation

A neural signal is an observation; a movement is something we can measure. NeuroTranslation is a proposed field for mapping neural signals and representations between clearly defined contexts and testing what those mappings can tell us.

Read the [current R9 paper drafts](papers/): technical and accessible editions of the NeuroTranslation and Brain2Body papers, with their matching manuscript source. The project is also developing models and an interface. No validated downloadable Large Movement Model or GUI is available yet.
