# NeuroTranslation

A neural signal is an observation; a movement is something we can measure. NeuroTranslation is a proposed field for mapping neural signals and representations between clearly defined contexts and testing what those mappings can tell us.

The project is developing models, an interface and two papers. The [paper drafts](papers/) are available for reading and development. They are working material, not validated clinical or biological results. No validated downloadable model is available yet.
