# Two papers, each written twice

Each paper has a Technical edition, for readers who want the method, and a Simple English edition, which explains the same things in ordinary words and takes more pages to do it.

| | Technical | Simple English |
| --- | --- | --- |
| *NeuroTranslation: A New Paradigm In Brain-Body Mapping.* | [PDF, 153 pages](current/neurotranslation-technical.pdf) | [PDF, 188 pages](current/neurotranslation-explained.pdf) |
| *Brain2Body: The Next Generation In Body-Brain Interfacing.* | [PDF, 136 pages](current/brain2body-article.pdf) | [PDF, 152 pages](current/brain2body-simple-english.pdf) |

**NeuroTranslation** asks what a recording adds once a model already knows the movement. It reports a macaque study in which two networks lowered the average error and still failed the test set for them, and the studies on people that are listed on [the studies page](../benchmarks/README.md). Then it proposes the larger model and the recording study that would test it.

**Brain2Body** starts somewhere else: let a computer guide a hand through a tune, then stop the guidance. What can the person play now? The paper is a proposal for telling help from learning. It reports no experiment on that question.

## How to read them

Start with a Simple English edition. [Read all four online](https://eliminatenoise.github.io/NeuroTranslation/papers/current/), or [download them in one ZIP](downloads/NeuroTranslation-Brain2Body-Papers.zip) and unpack the whole folder so that the links between its files work.

## What review they have had

None from outside the project. "Working Draft — Review Pending" is printed on each title page, and it is true.

The four files were last built on 19 November 2026. The newest study, number 23 on the studies page, is not in them yet. Where a paper and a results file disagree, the results file is right: [the studies page](../benchmarks/README.md) is written from the results files.

## Source, checksums and licence

- **Source.** [One ZIP](downloads/NeuroTranslation-Brain2Body-Papers-Source.zip) of 77 LaTeX and BibTeX files. It is not yet enough to rebuild the PDFs: the figures and two input files are missing from it, and its own README names them.
- **Checksums.** [`current.json`](current.json) names the edition and gives the checksum of each ZIP ([papers](downloads/NeuroTranslation-Brain2Body-Papers.zip.sha256), [source](downloads/NeuroTranslation-Brain2Body-Papers-Source.zip.sha256)). [`current/manifest.json`](current/manifest.json) gives the checksum and page count of each PDF.
- **Licence.** The project's own text is dedicated to the public domain under CC0 1.0. The fonts inside the PDFs and the recordings behind the studies have their own terms: [fonts and paper notices](current/NOTICE.md), [dataset credits](../docs/RIGHTS.md).

Each new edition replaces these files in place. Earlier editions are in the repository's history.
