These are working drafts intended for the finished project. R8 repairs formatting, including arrow glyphs, wrapping and section starts. Review accepted the affected formatting and source-to-PDF pairing. Of 522 rendered pages, 109 received recorded visual inspection; 413 remain unviewed. The independent reviewer viewed 23 pages within those 109.

Whole-paper prose, scientific claims, citation meaning, rights and reference review remain unfinished. Native export, accessibility and use on another machine also need review. The papers do not establish a validated model, GUI or generalization result. MyoHand contributes a simulated software diagnostic only. The completed LINK comparison retains its negative results: 18 fits and 720 saved epochs, with both model-admission rules and all five benefit claims failing.

The source snapshot includes manuscript text and bibliography. External figures, fonts and other linked build dependencies are not bundled, so this is not a standalone reproducible build. See the [third-party notices](drafts/r8/NOTICE.md).
