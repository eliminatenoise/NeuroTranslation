# Experimental R11 manuscript source

These are the existing R11 source drafts for **NeuroTranslation: A New Paradigm In Brain-Body Mapping.** and **Brain2Body: The Next Generation In Body-Brain Interfacing.**, in technical and accessible editions. Read the source to inspect how the argument, methods, citations and stated limits were being revised.

No matching R11 PDFs were produced. The [R9 papers](../../README.md) remain the latest actually rendered edition, with their [reading-aid erratum](../../errata/r9-reading-aid-metadata.txt). An R9 PDF must not be treated as the rendered output of these R11 files.

This is a source preview, not a standalone build package. Figure, font and some historical dependencies referred to by the manuscripts are not bundled here. External symlinks were not copied. The source retains its scientific uncertainties, unresolved references and negative findings; publishing it does not settle them or demonstrate a biological capability.

The files also preserve their historical terminology context. Their proposed G35 changes were **unadopted** in this source snapshot. They do not replace the project's current glossary or establish that those proposals were accepted. Current repository context identifies the separate glossary revision used for this publication's descriptions.

The [manifest](MANIFEST.json) identifies the 71 unchanged manuscript, citation and explicitly selected public-aid files. Internal registries and histories, private custody records, model weights, checkpoints and recordings are excluded. No assembler, compiler, model or manuscript generation was run for this preview.

Project-owned contributions use the repository's [CC0 dedication](../../../LICENSE). Cited works and third-party assets keep their own rights. The existing [paper notices](../../drafts/r9/NOTICE.md) identify earlier font and asset conditions; they do not grant permission for unbundled material. Development remains paused except for publishing these existing outputs.
