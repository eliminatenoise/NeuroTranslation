# What helps forecast a wrist turn?

The wrist turns towards a target. Recent angles and cue time already tell a model something about the next turn. NeuroTranslation asks what scalp and forearm recordings add to that forecast. Brain2Body uses the same experiment to ask what evidence a later feedback or teaching claim would need.
