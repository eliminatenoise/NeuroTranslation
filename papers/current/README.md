# NeuroTranslation and Brain2Body: the four papers

*NeuroTranslation: A New Paradigm In Brain-Body Mapping.* asks what a recording of brain or muscle adds once a model already knows how the body has been moving.

*Brain2Body: The Next Generation In Body-Brain Interfacing.* asks what a person keeps when a machine guides their hand through a skill and then stops.

Each is written twice: a Technical edition, and a Simple English edition that explains the same things in ordinary words.
